**고쳐 받아들인 것**:

## 0. 무엇을 왜
사용자(2026-10-28): "그래 해상도 버그부터 고치고 자 고정해줘. 그 이후 작업은 순서대로 진행하자." 해상도 버그(P0)는 58a8efe(§169.2), §171 macroGrad 기본 끔(250ce31) — 이제 하네스 = 기기 조건(quality `low` · resolutionScale 0.5 · 시간 업스케일 켬 · 앱 기본 옵션). 이 자는 **알갱이 고치기 후보를 순서대로 판정하는 자**입니다.
질감 감사(§169.1, scratchpad `texture/critic.md`)의 결론: 기기 알갱이는 잡음 **종류**가 아니라 **표본·조명**에서 옵니다 — (a) 구름 안 1차 보폭이 최소 50 m 에서 걸음마다 ×1.01, 빈 날씨에선 mip 으로 maxStepSize 쪽 → 첫 적중 직전 증분 120~1500 m(§7.1)가 빛 침투 깊이 ~7 m(적운 핵 σ ≈ 0.14 /m)보다 훨씬 커서 화소마다 "무작위 깊이의 첫 표본 하나"가 밝기를 정함, (b) 해 쪽 행진 6 걸음의 첫 걸음 41.7 m 가 구름 속에서 τ ≈ 5.7 씩 계단, (c) 모양 잡음 침식이 문턱 자르기. 근거로 인용되는 §130 흐름 C2(같은 백색 잡음 지터로 알갱이 0.047 → 0.005, 사진 0.011, `RULER-flow.md:167`)에는 **단서**가 있습니다: 그 web-repro 행은 실제로 res 1.0·캔버스 540×1200·다른 필터 사슬·×3.4 재표본이었고 C2 는 더 성긴 실현이었습니다. **P0 뒤 기기 알갱이는 아직 아무도 재지 않았습니다**(C0 를 먼저 그리는 이유, §5.4).
**왜 새 자인가**:
- 지금 자의 알갱이 문(`granSpatial ≤ q75`, 폭 320)은 하네스 크기에서 알갱이를 못 봅니다(low Als50 0.010 < 적운 사진 q25 0.040). 하네스 F-std 텍셀(가운데 0.227°)이 기기 텍셀(0.0566°)보다 각도로 4 배 거칩니다.
- 사진은 시간 흔들림을 못 잽니다. 기기는 바뀐 뒤 16~24 프레임에서 **한 장으로 멈추므로**(`SkyScene3D.tsx:1986,2008,2110,2115`) 화소당 표본 흔들림이 곧 "정지 화면에 얼어붙은 알갱이"입니다(지터가 갱신마다 독립일 때만 — E4 는 예외, §1.5).

### 2.2 주 지표 — σs(표본 오차, 장면 선형, 해석 앞)
- 텍셀 마스크(구름 버퍼): 안쪽 I = 창 평균 알파 ≥ 0.9 이고 3×3 전부, 테두리 R = 0.15 ≤ 알파 < 0.9; 기준의 반복 상한 텍셀 뺌; H-dev 는 고도 띠. 짝 비교는 **I_B∩I_E·R_B∩R_E**(겹침 < 0.7 무효).
- **σs(영역) = √(Σ_p var_p / Σ_p μ_p²)**(p = 마스크 텍셀, var·μ = 텍셀 표본 4 개의 휘도). 노출·톤 배율 불변(T4), 경사 불변(T3), 알려진 잡음에서 비 0.99(T2).
- 짝 비 = √(Σvar_E/Σμ_E²) ÷ √(Σvar_B/Σμ_B²), CI = 같은 4×4 텍셀 블록을 두 팔에 다시 뽑는 부트스트랩(2000, 씨앗 20261028 + 단위 이름 crc32). 최소: 텍셀 I 400·R 200, 블록 25.
### 2.3 표시 지표(기기 길, 부호; F-dev·H-dev)
- 부호 V = 255·sRGB(clip(L))(8 비트 디더 앞). CSF = Mannos–Sakrison 정점 1(≈ 7.9 cyc/°), 기기 0.0602 mm/화소·30 cm = 0.0115°/화소, 대칭 확장 FFT. 화소 마스크 = 원 알파로 I(5×5 전부 ≥ 0.9)·R, 포화 합집합 뺌, 가장자리 8 화소 뺌; 최소 I 1600·R 800 화소; 블록 16×16 화소.
- **tCSF** = √mean_M var_k(CSF∗V_k)(정지 4 장, 잡음 제거 뒤 Ld, ddof 1) — 기기에 얼어붙는 알갱이의 보이는 크기. 기록: 25·40 cm, 반올림 부호 tCodeQ, ln(Ld + 0.01) 의 창 tStd(F-std 단위에선 나빠지지 않음 보조).
- **eCSF**(주 — E4·E3b) = median_k √mean_M (CSF∗(V^raw_k − V^raw_ref))² 를 √max(e² − refErr², 0) 로(refErr² = mean (CSF∗(V_A − V_B))²/4). **eCSFdev** = 같은 식, 잡음 제거 뒤 정지 대 skyDenoise(기준 평균).
- **보이지 않음(바닥)** = B 의 max(tCSF, eCSFdev) < 1.0 부호.
- **sparkFrac** = I∪R 에서 \|V_k − V(창 평균)\| > 10 부호 화소 비율의 4 장 중앙(§140 안쪽 0.04 회색 규칙); E4 는 \|V_k − V_ref\|.
### 2.4 보조·가드 지표
- **eBias** = median_I \|box_8(ln 평균_t Ld − ln Ld_ref)\|(둘 다 선형 평균의 로그 — 젠센 차 없음; ln(· + 0.01)) · eBiasMean 기록 · **aErr** = mean \|ᾱ − α_ref\| over (ᾱ ≥ 0.15) ∪ (α_ref ≥ 0.15) · **cf** = 알파 ≥ 0.15 비율(F-std 위 78 %).
- 밝기(창 평균 PNG): 구름 안쪽 중앙 L, 하늘(알파 < 0.02) 중앙 L, 포화 구름(세 채널 ≥ 250) 비율.
- **표류** D_lp = 마스크 안 17×17 평균으로 매끈하게 한 (ln 앞 32 평균 − ln 뒤 32 평균)의 RMS; 무효 = D_lp > 0.5·tStd 그리고 > 0.003(§1.5).
- **fetchCost** = 구름 패스 텍스처 읽기/텍셀 = x(1차 날씨) + y(모양 fetch, 1·2 차 모두) + z(해·땅 행진 걸음 = 그 날씨 fetch), 16 프레임(모든 Bayer 위상)·전 텍셀 평균; 비용 변형(앵커 6 개 정확히 한 번, 아니면 throw) · capFrac(반복 상한 표지) · 그림자 지도 패스·ALU 제외 · 정수 ≤ 2048 정확(반정밀도). wallMs 는 기록만.
- 기록: tail(I) = s_p/μ_p > 3·중앙값 텍셀 비율(동질 잡음 χ²₃ 기댓값 ≈ 9e-5), 빨강 잘림 비율, eFine(5×5 고역), speckleExcess·granSpatial.

## 5. 규칙
### 5.1 단위·유효
단위 = (장면, 방위, 틀, 영역 Int|Rim). 주 지표 = σs(E1·E2·E3·E3c·E5 계열) 또는 eCSF(E4·E3b — F-dev, 기준 있는 단위만). **유효 V** = 두 팔 captureOk · 텍셀 마스크 최소 · 겹침 ≥ 0.7 · 블록 ≥ 25 · (F-dev·H-dev) 화소 마스크 최소·겹침 · 표류 무효 아님 · (eCSF 주) 기준 유효. 분모는 B·E 의 측정 조건으로만 정합니다(결과값 아님).
### 5.2 단위 분류(B = 그 라운드의 기준)
- 표시 보조(나빠지지 않음): F-dev·H-dev 는 tCSF(E4 제외) + eCSFdev(기준 유효) + eCSF(σs 주이고 기준 유효), F-std 는 ln tStd(E4 제외).
- **바닥**: F-dev·H-dev 에서 B 의 max(tCSF, eCSFdev) < 1.0 부호 → 개선 셈 밖, 악화는 (주 또는 표시 보조가 악화 조건) 그리고 E ≥ 1.5 부호일 때만.
- **개선** = 주 비 ≤ r_i 그리고 90 % CI 상한 < 1 그리고 표시 보조 비 모두 ≤ 1.10. **악화** = 주 또는 표시 보조 중 하나가 비 ≥ r_w 그리고 CI 하한 > 1 그리고 절대 증가 ≥ δ(σs 0.003 · 부호 0.25 · ln 0.003). 그 밖 **동률**.
- 문턱 세 벌: 기본 (0.80, 1.10) · 넓게 (0.85, 1.15) · 좁게 (0.70, 1.05).
### 5.3 후보 판정
**주장 K**(렌더 전 고정, 물리에서): K(E1) = 첫 적중 직전 증분(§7.1, 틀 가운데 고도) ≥ 100 m 인 장면·틀 · K(E2) = 해 ≥ 3° 이고 {cu35, sc25, sc85, ac60, ci60}(L·H) · K(E3)·K(E5) = {cu35, sc25, sc85, ac60} 전부(L·T·T4·H) · K(E4) = F-dev 전부(eCSF 단위).
세 벌 각각에서:
- (i) 개선 ≥ 0.5·\|V_imp∩K\|, (ii) \|V_imp∩K∩P\| ≥ 20 이면 개선 ≥ 0.5·\|V_imp∩K∩P\|, (iii) 악화 ≤ 0.10·\|V\| 그리고 악화 ≤ 0.10·\|V∩P\|, (v) **종류 기준**: L 5 층 중 K 유효 단위 ≥ 3 인 층에서 층 중앙 비 ≤ r_i 인 층 ≥ 60 %(층 < 3 이면 '평가 불가(종류)').
공통:
- (iv) **장면 묶음**: 장면 값 = 그 장면 K∩P 유효(바닥 아닌) 단위의 ln 비 중앙값, 장면 ≥ 6. 장면 부트스트랩(2000) 중앙값의 90 % 상한 < ln 0.90 **그리고** 장면 부호 검정(ln 비 < 0 인 장면 수 ≥ P(Bin(n, ½) ≥ c) ≤ 0.05 인 c).
- (vi) **H-dev**: 팔이 H(F-std H·O45) 단위를 주장하면 H-dev 4 잡 중 ≥ 3 에서 Int σs 비 ≤ 1.0, H-dev 악화 없음.
판정: \|V∩K\| < 40 → **평가 불가** · \|V_imp∩K\| < 40 → **평가 불가(이미 바닥)** · 종류·장면 수 모자람 → 평가 불가(종류·장면) · (iv)(vi) 와 세 벌 모두 (i)(ii)(iii)(v) → **통과** · (iv)(vi) 와 기본 벌만 → **불확정(효과 문턱)** · 그 밖 **불합격**.
보고(판정 아님): 단위 비의 묶음별 중앙, tCSF 25/40 cm, tCodeQ, 꼬리, 빨강 잘림, raw 값, \|Δln 구름 L\| > 0.05 단위.
### 5.4 라운드 순서(사용자: "순서대로")와 멈춤
- 보정(§8.3) → 손잡이 구현·G0 번들(§12) → **C0 를 먼저 혼자** → 멈춤 검사 → R1 E1(E1a.3·E1a.0·E1b) 기준 C0 → R2 E2(E2a.8·E2a.6·E2b, 조건부 E2c) 기준 B1 → R3 E3(E3·E3b + 진단 E3c) 기준 B2 → R4 E4 기준 B3 → R5 E5(E5−·E5+) 기준 B4 → R6 결합 + 확인 집합 Q. B_k = B_{k−1} + 라운드 k 의 채택(없으면 그대로).
- B_k 재사용: P0n 이 허용하면 앞 라운드의 그 팔 렌더를 그대로(같은 번들·잡 sha → run-grain 이 건너뜀), 아니면 'B{k−1}' 을 라운드 페이지에서 다시 그림. 라운드 잡은 단위마다 기준 팔을 먼저, 후보를 바로 뒤에(`grain.py --select --order unit`).
- **멈춤 규칙**: 기준 팔의 제품 단위(F-dev, (장면, 방위, 영역), 마스크 최소 충족) 중 ≥ 80 % 가 보이지 않음(B 의 max(tCSF, eCSFdev) < 1 부호) → 다음 라운드를 그리지 않고 사용자에게 묻습니다(P0 뒤 기기 캡처와 함께). C0 뒤, 그리고 라운드마다 새 B_k 로.
### 5.5 채택(라운드 안)
알갱이 '통과' + 가드 전부 통과(평가 안 된 가드가 있으면 '가드 미평가' — 채택 안 함) + 비용(G8, 누적 장부) → **채택 후보**. 여럿이면 K∩P 개선 단위가 많은 쪽 → fetchCost 중앙 낮은 쪽 → 하네스 값(E1a·E2a·E5) 쪽. 알갱이·다른 가드는 넘고 **비용만** 실패 → **비용 보류**(E2a.8 이면 R2 안에서 E2c). G1 만 실패 → **면적 재맞춤 필요**(채택 안 함, RULER-cover 재맞춤 입력). E3c 는 채택 안 함. E5 는 전역 하나.
### 5.6 결합 R6·확인 집합 Q
- B_final = C0 + 채택 전부로 held-out 전체를 한 번 더, **C0 대비**: K = 채택 팔들의 K 합집합(E4 가 들면 eCSF 주), 가드 전부, 누적 fetchCost 중앙 ≤ cap_cum. 비용 보류 후보 H 는 B_final + H 로 같은 규칙. 결합 실패 → 마지막 채택부터 하나씩 빼고 다시(최대 2 회, held-out 에서만).
- 그다음 **Q 를 한 번**: C0 대 B_final, σs 주 + tCSF 나빠지지 않음, 같은 단위 규칙·장면 묶음(\|V∩K\|·\|V∩K∩P\| 최소 20). **Q 가 '통과'여야 채택 권고**, 결과는 늘 보고.
- 기기 후속(채택 뒤, 사용자 기기): 개발 설정 경로로 손잡이 켜기(기본 끔), 제품 장면 3 개에서 C0 대 B_final 을 QR 로 상태 기록·`volumetricStats` frameMs/resScale/quality 기록; 기기 문: resScale 0.5 유지, 10 초 팬에서 frameMs EMA ≤ 45 ms. 앱 기본값은 사용자 결정.
### 5.7 조건부 결과의 읽기(미리 적음)
- E1a.3 통과·비용 × → 고른 보폭 줄이기는 듣지만 비쌈 → E1b 가 길. E1a.0 만 통과, E1b 불합격 → 정제 보폭 50 m 가 침투 깊이 7 m 보다 큼 → 다음 자: 이분 탐색 + 10~15 m 안쪽 보폭(E1c).

- E2a.8 통과·E2a.6 이 L 에서 G7/G5 실패 → "12° 아래 해 행진 닿는 거리 ≥ 1 km" 를 앱 상수에.

## 9. 알려진 한계
- 하네스 ≠ 기기: 지형(DEM)·바람 흐름·조절기·합성기 마지막 Catmull-Rom 확대·출력 디더(±0.5 부호)가 없음(잡음 제거는 같은 글자), 기기는 `macro: volumetricMacro ?? 1` 로 돌고 하네스 grain 잡은 앱 기본(macro 0) — 이 장면들은 고리 자료가 없어 무관. SwiftShader 부동소수·비결정성(§1.5). 시야 60° 만(사용자는 20~120° 로 바꿀 수 있음).
- F-dev 창은 해 12° 미만에서만 기기 등가(그림자 단계 맞춤이 시야에 걸림) — 그래서 H 는 F-std + H-dev 4 잡.
- 기준은 같은 렌더러의 수렴값(같은 밉·끝내기 규칙)이지 실제 하늘이 아님. minTransmittance 0.1·알파 remap 의 계통 오차는 이 자가 보지 않음. 기준은 mean(tone) 이지 tone(mean) 이 아님(§1.5).
- 잡음 실현은 noiseSeed 로 바꿀 수 있지만 판정은 씨앗 12345 하나(A/A 로 실현 사이 변동의 크기만 잼). 기기는 frame 이 계속 오름.
- 움직임(시간 끌기·화면 끌기) 중 재투영·클리핑 깜빡임은 범위 밖. Live Photo MP4 는 센서·코덱 잡음이라 tStd 바닥으로 안 씀.
- 낮은 해 사진 사분위 없음; 사진 시야 모름. "보이지 않음" 1 부호·CSF·30 cm 는 가정(25·40 cm 기록). 효과 문턱 0.80/1.10·50 % 는 설계 선택(세 벌로 민감도).
- 비용 대리값은 텍스처 읽기 수이지 모바일 GPU 시간이 아님 — 기기 문은 채택 뒤(§5.6).
- 장면은 한 곳·한 날·단층; 다층은 박명 가드뿐. E5 는 공유 균일변수라 전역 결정만. E3 은 지금 면적 역표와 안 맞을 것이 예상됨.
- §7 의 수치는 코드 읽기·근사 계산이며 렌더로 확인되지 않음. 연기 시험 값(§11.0)은 개발 장면 하나의 도구 점검.
