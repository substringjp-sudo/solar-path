**사전 등록**: 이 문서·`phys3.py`·`phys3-photo-quartiles.json`(phys3.py 해시 포함)·`jobs-phys3.json`·`eval-phys3.sh`·하네스 번들 해시(§10)를 held-out 렌더를 **한 장도 그리기 전에** 커밋합니다.
렌더를 본 뒤 규칙·문턱·장면·판정 코드를 바꾸지 않습니다. 초안은 렌더 전에 독립 비판 3 관점(복사 전달 물리·통계/절차·셰이더 구현)의 검토를 받고, 결함을 고친 뒤 고정합니다.

## 0. 무엇을 왜
§137 D1: 부분 덮임 장면의 어두움비(구름 p10 ÷ 하늘 중앙값)가 사진보다 2 배 밝고(층적운 렌더 1.80·2.18 vs 사진 0.58/0.95/1.41), 햇빛 확산 투과 항 `thru` 를 끄면 사진 범위로 들어옵니다(f 0.87).
그런데 `thru` 를 끄면 **그늘이 푸르러집니다** — 새 지표 shadeBlue(그늘 B/R ÷ 밝은 곳 B/R, §2) 가 P0 1.3~1.8 → T0 2.0~2.8, 사진은 종류별 q75 가 1.13~1.63. 하늘빛을 끄면(K0) 1.0~1.4 로 희어집니다. 즉 그늘의 빛은 "흰 햇빛 확산 + 푸른 하늘빛" 두 몫이고, 지금은 흰 몫의 **양**이 틀렸습니다.

**원인(코드 읽기, 렌더 전 가설)**: `thru` 는 위쪽 광학두께를 `τ_up = β_표본 × (꼭대기까지 거리)` 로 셉니다 — 표본의 **국소** 소광입니다. 종류 단면은 밑면에서 램프(층적운 `base` 0.08 → 60 m)로 밀도가 0 에서 오르므로, 아래에서 본 광선이 처음 만나는 램프 표본들은 β 가 작아 τ_up ≈ 1~20 으로 보이고 `thru` 는 거기서 **최대(햇빛의 0.28~0.36 / 4π)** 입니다. 실제 그 위 기둥은 τ 100 을 넘는데도요. 램프 자체의 광학두께가 6 이 넘어 보이는 밑면 전부가 이 표본들로 결정됩니다.
같은 표본에서 takram 의 다중 산란 근사(해 쪽 행진 + 그림자 지도의 **진짜 기둥** τ)는 0.01 입니다. `thru` 의 식 (1 − e^(−0.15τ))·2/(2 + 0.1τ) 이 τ 10~20 에서 봉우리인 것 자체는 틀리지 않습니다 — 판의 **확산** 투과(전체 투과 − 직접 투과)도 τ' ≈ 1.5(g 0.85 에서 τ ≈ 10)에서 최대입니다(`phys3-test.mjs` 표). 따라서 식의 모양이 아니라 **τ_up 을 국소 소광으로 센 것**이 결함이고, 같은 기둥 τ 에서는 지금 식과 두-흐름이 양도 비슷합니다(τ 10: 0.365 vs 0.317, τ 165: 0.030 vs 0.051).
물리를 켜 얇아진 층(P1)이 더 밝아진 것(§137 D1: P1 어두움비 2.36·3.24)도 같은 결함으로 설명됩니다: 램프 표본의 국소 β 가 더 작아져 τ_up 이 봉우리 쪽으로 갑니다.

## 1. 후보 — 표본 하나의 광원 (구름 패스만; 그림자 패스는 그대로)
지금(L0 = P0): radiance = sun·MS(τ_sun, cosθ) + 지면반사 + sky·(1/4π)·skyGradient·max(0.35, e^(−ao·depth)) + **sun·(1/4π)·thru·(1 − e^(−0.15τ_up))·2/(2 + 0.1τ_up)·max(0.28, e^(−0.035τ_up))·max(beamT, 0.25)**; ×산란계수 ×가루.

공통 기호 — 수직 광학두께는 해 쪽 경로를 평면평행으로 세워서: μ0 = max(0.05, n·sunDir),
- τ_above = opticalDepth(해 쪽 행진 + 그림자 지도, 이미 MS 가 쓰는 값) × μ0,
- τ_total = max(τ_above, τ_BSM(층 밑면 점) × μ0). 층 밑면 점 = position − n·(height − h_min(층)); 그림자 지도 밖(height ≥ shadowTopHeight)이면 τ_total = τ_above + β_표본·hf·H(지금 방식으로 아래쪽만).
- 비대칭 g = 0.85(물방울; 얼음 층도 같은 값 — 얇아 영향 없음, §9), 축척 τ' = (1 − g)τ.
- 확산 투과 T(τ'_t) = 1 / (1 + 0.75 τ'_t) (점근 이론, King & Harshvardhan 1986 의 보존 산란 근사).
- 확산장(에너지 밀도 ∝ F↓ + F↑, 두-흐름은 τ 에 선형): D = (2 − T)(1 − x) + T·x − e^(−τ'_above/μ0), x = τ'_above / τ'_t, D ≥ 0 으로 자름.
  얇은 층(τ_t → 0): T → 1, D → 0(직접광은 MS 가 맡음). 두꺼운 밑면: D → T. 꼭대기: D → 1 + R = 2 − T.
- 꼭대기 조도 E_top = sunIrradiance·μ0 + 0.5·skyIrradiance (takram sunIrradiance 는 코사인이 빠진 값, skyIrradiance 는 구 전체 스칼라 → 반구 ≈ ½).

| 후보 | 바꾸는 것 | 무엇을 가르나 |
|---|---|---|
| **L0** | 지금(P0) | 기준 |
| **L1** 기둥 τ | `thru` 식·바닥값은 그대로, τ_up 만 **τ_above(기둥)** 로 | 원인 가설(국소 β)만 분리 |
| **L2** 두-흐름 | `thru` 블록 전체를 **E_top·D·(1/4π)** 로 교체(0.28·0.25 바닥값 없음). 하늘빛 항·ao 는 그대로 | 양을 물리로, 색을 꼭대기 조도(햇빛 : 하늘 ≈ 5 : 1 → 흼)로 |
| **L3** L2 + 하늘빛 감쇠 | takram 하늘빛 항의 `max(0.35, e^(−ao·depth))` 를 **e^(−τ'_above)** 로(ao·바닥값 은퇴) | 푸른 몫도 기둥 τ 로 |
모든 후보는 옵션(`diffuse: 0|1|2|3`, 기본 0)이고, 끄면 셰이더 글자가 P0 과 같아야 합니다(G3). 소광은 손값(물리 끔) — 물리(P1)는 다음 자에서 이 결과 위에.

## 4. 규칙(칸 = (장면, 방위, 지표); 후보·L0 모두 유한한 칸 V 위에서)
- **RC 그늘 색**(새, 8 장면 × 3 방위 = 24 칸): ○ = shadeBlue ∈ [q25, q75]. 통과 = 점수 ≥ L0 그리고 평균 D_c ≤ 0.85 × L0 평균 D_c(D_c = |ln(v/q50)| / ln(q75/q25)) 그리고 점수 ≥ 0.5|V|; |V| < 18 이면 평가 불가.
- **R1** 밝기비·어두움비(cu·ac·ci·sc25·sc85, 최대 30 칸): §137 과 같음 — 점수 ≥ L0, 평균 D ≤ 0.85 × L0, 점수 ≥ 0.5|V|.
- **R2** 조각 간 밝기 차: 점수 ≥ L0.
- **R3c-struct·grain**(st·as·ns·sc85, 기본 문턱): 점수 ≥ L0(가드 — 나빠지지 않을 것). 폭 260·208 은 보고만.
- **G1'** CLIP 라벨(ac·ci, 방위 3): 맞는 방위 수 ≥ L0.
- **G2** 박명 색(`genus/twilight-hue.py --horizon`): 자주 ≤ 0.10, 푸른 ≥ 0.10, 하늘 휘도 중앙값 ≥ 0.5 × L0 — 두 장면 모두.
- **G3** 끄면 그대로: 셰이더 글자 동일 + 상태 해시 동일(28 장면, `state-hash.js`).
- **G4** 장면별(방위 평균) cloudFrac |Δ| ≤ 25 %(알파는 조명과 무관 — 환경 점검).
- **채택 정책**: 위 규칙을 **모두** '통과'한 후보가 **채택 후보**. 여럿이면 RC + R1 점수 합이 큰 쪽, 같으면 단순한 쪽(L1 < L2 < L3). 하나도 없으면 기록만(기본 0). 기본값으로 켜는 것은 사용자 결정.
- 폭 민감도(R3c)는 §137 과 같이 보고만.

## 6. 예측(렌더 전)
- L1: 어두움비 sc 1.8 → 1.0~1.2(T0 0.88 과 P0 사이), shadeBlue 는 흰 몫이 줄어 **오름**(sc 1.4 → 1.6~1.9) → RC 는 L0 보다 나쁠 수 있음. R1 통과 가능.
- L2: 같은 기둥 τ 에서 양은 L1 과 비슷(τ 165 밑면: L1 0.030·바닥값 포함, L2 0.051), 차이는 (a) L1 은 햇빛에 μ0 를 곱하지 않음(해 49° 에서 L2 가 0.76 배), (b) L2 는 하늘 반구 조도를 섞어 꼭대기 조도 색, (c) 바닥값 없음. RC·R1 둘 다 L0 이상이 목표.
- L3: 하늘빛이 기둥으로 감쇠 → 두꺼운 밑면이 가장 흼(shadeBlue ↓), 얇은 가장자리는 그대로. 박명(G2)에서 하늘빛 감쇠가 자주빛 몫을 바꿀 수 있음 — 가드가 가름.
- 얇은 권운(ci)은 D ≈ 0 이라 세 후보 모두 L0 과 거의 같음(RC·R1 의 ci 칸은 변화 없어야 함).
- 어느 후보도 하늘 기준(렌더 하늘 밝기)을 바꾸지 않으므로, 어두움비의 남은 차이는 하늘 쪽 몫.

## 7. 구현 메모(검토 대상)
- 그림자 지도 한 번 더 읽기(층 밑면 점): `sampleShadowOpticalDepth(bottom, 0.0, 0.0, jitter)`; 밑면 점이 그림자 지도 밖이면 0 → `max(τ_above, ·)` 가 τ_above 로 떨어짐. 해가 지평선 아래(μ0 ≤ 0.05)면 E_top 의 햇빛 몫 ≈ 0 → 하늘 몫만.
- 순수 함수 `cloudDiffuse.ts`(T·D, GLSL 문자열 생성에 같은 상수) + `phys3-test.mjs`(극한·단조·에너지: D ≤ 2, τ_t → 0 에서 0, 꼭대기 2 − T, 밑면 T).
- 옵션 `diffuse` 는 §136 얼음 코드처럼 **켤 때만 삽입**(L1 은 thru 블록 치환, L2 는 교체, L3 는 교체 + 하늘빛 줄 치환), 끄면 원문.

## 8. 한계(미리 적음)
- 평면평행 두-흐름을 3D 구름 안에서 표본마다 — 옆면에서 새는 빛·이웃 구름 없음. 적운 옆면 그늘(사진 shadeBlue 1.43)은 이 모형 밖.
- τ_total 이 그림자 지도 해상도·캐스케이드에 묶임; 해가 낮으면 μ0 바닥값 0.05 가 τ 를 과대평가.
- MS 하위 옥타브와 D 가 중간 τ(3~20)에서 겹침(둘 다 다중 산란) — 상수로 가르지 않고 자로만 봄.
- 사진 shadeBlue 는 JPEG 톤 곡선 영향(비율이라 일부 상쇄), 사진 표본 n 22~58.
- g 고정 0.85; 얼음 0.75~0.8 미적용.
