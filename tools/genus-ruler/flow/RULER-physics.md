## 0. 고치려는 불만

사용자(서울 10/12): "구름별로 밀도도 다를텐데 다 비슷한 것 같고", "거대한 볼륨의 구름은 겉모습이 단조롭다".
원인(§135.1): 종류별 소광 `GENUS.densityScale` 가 판정기로 고른 손값이라 sc·cu 0.22, ac·st 0.2, as 0.15, ns 0.28 /m 로 거의 같습니다.
날씨 밀도 1 인 기둥의 광학두께로 바꾸면 고적운(두께 400 m) ≈ 50, 고층운(1.5 km) ≈ 140, 난층운 ≈ 560 — 문헌 범위(Ac 2–20, As 2–40,
Ns 40–400)를 크게 넘어 **얇아야 할 종류가 모두 두꺼운 회색 덩어리**가 됩니다. 산란 위상은 모든 층이 같아(takram 전역 HG 혼합)
얼음 구름의 무리(22°)도 없습니다.

## 1. 후보

| 후보 | 내용 |
|---|---|
| P0 | 지금(물리 끔). |
| P1 | 소광·세로 단면만 물리: `densityScale` = 층 꼭대기 β(`cloudPhysics.layerPhysics` — 높이마다 센 β 의 기둥 합 τ_core 를 단면 평균 0.597·H 로 나눈 값), `densityProfile` = 단열 h^(2/3) 맞춤(−0.2795·e^(−6.56·hf) + 0.7209·hf + 0.2795) / 얼음 층 평평(1). 구름·그림자 두 패스 모두(takram 층 값). |
| P2 | P1 + 얼음 무리(구름 패스) + 얇은 층 가루 효과 끔. |

P2 셰이더 상수(지금 고정): 첫 산란 차수(e^(−τ_sun))에만 더하는 무리 위상 Δp(θ) = halo · [A₂₂·R(θ; θ_c, 0.4°, 1.2°) + 0.15·A₂₂·R(θ; θ_c46, 0.6°, 2.0°)],
A₂₂ = 0.25 /sr, R = smoothstep(θ_c − 0.4°, θ_c, θ)·e^(−max(0, θ − θ_c)/w). 중심(R·G·B) 21.6·21.9·22.3° / 45.6·46.0·46.6°(분산 — 안쪽 붉음).
halo 레인 = 종류 무리(cs 1 · ci 0.5 · 모루 0.3, 나머지 0) × 광학적 얼음 비율. 가루(takram powder `1 − 0.8·e^(−150β)`) 무게 = smoothstep(1, 5, τ_렌더)
(τ_렌더 = 날씨 밀도 1 인 기둥에 종류 봉투 min(1, edge·hs) 를 곱한, 렌더가 실제로 그리는 기둥의 광학두께)
— 광학두께 1 아래 층(권운류)은 가루 효과 0(얇은 층 전체가 "표면"이라 어둡게 할 근거 없음; P0·P1 은 권운을 2.5~4 배 어둡게 함).

열역학 입력: 하네스 낮 장면은 입력이 없어 표준대기(지표 15 °C), 서울 장면은 `phys-test.mjs` 의 SEOUL 단면. 앱은 예보(§135.3)에서.
적운류(cu·cg·cb) 밑면 = 지면 + 125 m·(T − Td)(물리 켬 + 지상 이슬점이 있을 때만, 앱 경로 — 하네스 장면은 밑면을 직접 줌).

## 4. 규칙(모두 phys.py / fm.py 로 기계 판정)

통계는 방위 3개의 중앙값(nanmedian). 사진 사분위 = `phys-photo-quartiles.json`(R1·R2), `photo-flow-quartiles.json`(R3, fm.py 동결).

- **R1 종류별 밝기비(주 규칙)** — 장면 cu·ac·ci·sc25·sc85 의 brightRatio·darkRatio 가 그 종류 사진 [q25, q75] 안이면 ○(10 칸).
  거리 D = Σ |ln(v / q50)| / ln(q75/q25)(IQR 단위). **통과: ○ 수 ≥ P0 의 ○ 수 그리고 D ≤ 0.85 × D(P0).**
- **R2 구름마다 다른 밝기** — 장면 cu·ac·ci·sc25 의 pieceLogSD ≥ 사진 q25(조각 4개 이상일 때만 셈). **통과: ○ 수 ≥ P0.**
- **R3 흐린 하늘 밀도 분포** — 장면 st·as·ns·sc85 의 fm.py `density` 군(shadeRange iqr · logIQR ≥ q25 · darkFrac ≥ q25 · edgeWidthPx ≥ q25)
  실패 수 합. **통과: 실패 합 ≤ P0.**
- **H 무리(P2 만)** — halo 장면 E22(phys.py --halo). **통과: E22(P2) − E22(P0) ≥ 0.04 이고 |E22(P1) − E22(P0)| ≤ 0.02(대조).**
  안쪽 붉음 redInner 는 기록만.
