# RULER-flow — 대기 흐름 구름 모형 (2026-10-07, 렌더 전에 고정)

사용자: "구름이 알갱이처럼 보이고 위아래로 뚱뚱하기만 하고, 여러 구름이 겹치며 합쳐지고 물결·흐름처럼 만들어지지 않고, 구름마다 다른
형태가 아니고, 대기의 흐름과 기압 변화 같은 유기적인 모습이 없고, 밀도 차이와 그에 따른 색·그림자 변화도 없다."
설계(판정단 3명 만장일치, scratchpad `flow-design.md`): 날씨 원시장을 "정적 도형의 합집합"에서 **한 2-D 순압 와도 흐름(트리그 모드
압력장 ψ₀ → Dζ/Dt = 0 반라그랑주 라벨맵)이 변형한 종류별 템플릿 + 대규모 수분장 + 전단파**로 바꾸고(`cloudFlow.ts`), d 를
정규화 응결량으로 읽어 셰이더에서 연속 밀도(`cloudFlowShader.ts`)로 그립니다. 운량 분위수 문턱은 그대로(위에서 본 면적 = 운량).

이 자는 **첫 렌더 전에** 커밋합니다. 렌더 뒤에는 값·문턱·후보를 바꾸지 않습니다(RULER-sc-low C1 교훈). 최종 판정은 사용자의 눈이지만
무엇도 눈만으로 넣지 않습니다(RULER.md).

## 1. 질문
흐름 모형(C1), 연속 밀도(C2), 층별 드리프트·기울임(C3)이 여섯 불만을 **사진 사분위** 기준으로 C0 보다 개선하면서 속 정체성·운량·노출·색
가드를 지키는가. 채택은 **속마다**(sc·ac·cu·ci 따로).
