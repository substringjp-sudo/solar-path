## 1. 막는 결함 — RULER-oro

### O-B1 G-rev 짝 차를 다른 집합에서 잼
- **문제**: ρ_res 는 S 에서, ρ_rev 는 S_rev 에서 잽니다. 그리고 \|S_rev\| < 20 인 장면은 c3 에서 빠집니다.
  - 그래서 c3 은 c2 와 다른, 크기를 정하지 않은 장면 집합에서 판정될 수 있습니다.
  - d 안에는 바람 뒤집기 효과와 상자 고르기 효과가 섞입니다.
  - "정의되지 않으면 0" 을 ρ_rev 에 쓰면 d = ρ_res 가 되어 보수적이지 않습니다.
- **근거** [computed, `stat/sim1.json`·`sim1b.json`]
  - 서울 타일과 합성 지형에서 \|S\| 와 \|S_rev\| 가 장면마다 다릅니다(19 대 11, 33 대 42, 63 대 75).
  - 독립 대용 잔차(null)에서 d 의 SD 는 S∪ = S ∪ S_rev 한 집합에서 잴 때보다 1.0~1.8 배 큽니다.
  - corr(ΔC, ΔC_rev)(S∪)의 중앙값은 −0.79 입니다.
- **고칠 글**
  - §4.3 원문 `  - 짝 차 d = ρ_res − ρ_rev 입니다. \|S_rev\| < 20 이면 그 장면은 짝 집합에서 빠지고, 수는 보고합니다.` →
    > - 짝 차 d 는 **같은 상자 집합** S∪ = S ∪ S_rev(눈 가림 밖, \|ΔC_b\| 또는 \|ΔC_rev,b\| ≥ 0.02)에서 잽니다. d = Pearson_{S∪}(ΔC, T − B) − Pearson_{S∪}(ΔC_rev, T − B) 입니다.
    > - S∪ ⊇ S 라 판정 장면은 하나도 빠지지 않습니다. c3 의 장면 집합은 c2 와 같습니다.
    > - 둘 중 하나라도 분산이 0 이면 그 장면의 d 는 0 입니다(보수적).
    > - 이유 [computed]: 서로 다른 집합에서 잰 두 ρ 를 빼면 null 에서 d 의 SD 가 1.0~1.8 배 커지고, 상자 고르기 차가 d 에 섞입니다.
  - §5.1 원문 `| c3 | **G-rev**: 중앙 (ρ_res − ρ_rev) > 0 이고 L95 > 0 |` →
    > `| c3 | **G-rev**: S∪ 위의 짝 차 d(§4.3)의 중앙 > 0, L95 > 0, 부호 뒤집기 p ≤ 0.025(§4.4). 장면 집합은 c2 와 같음 |`

### O-B2 의존과 구간 보정 — 날짜 블록이 너무 적고, 사이트 의존은 빠짐
- **문제 1: 날짜 블록 수**
  - 판정 장면은 13 날짜(+ 확장 ≤ 3)에 흩어지고, 날짜마다 1~5 장면입니다 [from doc, modis-times 키].
  - 이전 자들의 구간은 날 블록 30~38 개였습니다(RULER-source §S2, ringtruth Q2).
  - 블록이 ~12 개면 중앙값의 백분위 부트스트랩이 좁게 나옵니다.
- **문제 2: 사이트 의존**
  - 산악 사이트는 ≤ 6 곳이고, 한 곳의 지형이 ~13 번 되풀이됩니다.
  - 지형에 묶인 착시(눈·그림자·`land` 오프셋)나 사이트 고유의 예보 편향은 그 사이트의 모든 날에 함께 들어갑니다.
  - 날짜 블록은 사이트를 고정된 것으로 둡니다.
- **근거** [computed, `stat/sim2.json`·`sim2b.json`·`sim2c.json`]
  - 모형: 6 사이트 × 실제 13 날짜 키, 적용 확률 0.2~0.5, n 중앙 25(날짜 12 개). ρ_i = μ + u_사이트 + v_날짜 + e_i 이고, null 은 μ = 0 입니다.

  | 사이트 SD τ | 백분위 L95 > 0 의 실제 오류율(명목 0.025) |
  |---|---|
  | 0 | 0.035~0.048 |
  | 0.05 | 0.048~0.061 |
  | 0.10 | 0.071~0.110 |

  - **한 사이트 착시**(denver u = +0.25, 다른 곳 0, 점유 ~28 %): c2 거짓 통과 0.22 입니다. 사이트 하나 빼기(LOSO, 점 추정)를 더해도 0.21 이라 거의 막지 못합니다.

  - 사이트·날짜 두 방향 부트스트랩은 너무 보수적입니다(null 0.001~0.013, μ 0.10 에서 검정력 0.08~0.31). 이것도 권하지 않습니다.
  - **날짜 블록 부호 뒤집기 정확 검정**: 날짜마다 그날 장면들의 부호를 함께 뒤집는 2^G 가지를 모두 보고 중앙값을 통계량으로 씁니다. null 오류율 0.017~0.019(보정됨), μ 0.10 의 검정력 0.41~0.42(L95 만 쓰면 0.51~0.55)입니다.

### O-B4 null 모형이 몇 점을 내는지 정하지 않음
- **문제 1: 지형 높이 몫**
  - η_w 의 실수부 1/(1 + m²H_w²) 는 h 와 같은 위상이라, F 는 판정 창에서 h_sub 와 양의 상관을 가집니다.
  - 그래서 지형 높이에 묶인 착시는 ρ_res 를 0 이 아닌 쪽으로 끕니다. 눈·그림자·안개, 해안 `land` 오프셋 같은 것입니다.
  - §4.3 은 이것이 "바람에 짝수라 지워" 진다고 쓰지만, 창이 지형을 자르므로 장면마다 다 지워지지는 않습니다.
- **문제 2: 평균 회귀 몫**: T − B 는 B 와 음의 상관을 가집니다(유계 잔차, Barnes 평활). 그리고 S 위에서 ΔC 와 B 의 상관도 0 이 아닙니다.
- **근거** [computed, `stat/sim1b.json`, 합성 지형 6 개 × 바람 7 개 × B 2 개, 적용 같은 행 42 개]

  | 양 | 값 |
  |---|---|
  | corr(F, h_sub) · corr(F_rev, h_sub)(창) | 중앙 0.24 · 0.27, 장면마다 차 ±0.1 |
  | corr(ΔC, B)(S) | 10/50/90 % 에서 −0.08 / −0.02 / +0.04 |
  | corr(ΔC_rev, B)(S_rev) | 중앙 +0.01 |

  - 그래서 corr(T − B, h) = 0.3 인 착시 하나만으로 ρ_res ≈ +0.07 이 나옵니다. 이것은 예측 효과 크기와 같습니다.
  - 우세풍이 한쪽인 사이트에서는 이 몫의 일부(≤ 0.03)가 d 에도 남습니다.
  - corr(T − B, B) ≈ −0.4 [estimate] 이면 평균 회귀 몫은 장면당 ±0.03, 중앙 ≈ +0.01 입니다. d 에는 ≈ +0.013 이 남습니다.
- **고칠 글**
  - §4.3 원문 `  - 눈·안개·지형 높이에 따른 착시는 바람에 짝수라 지워지고, 바람받이·풍하 신호는 홀수라 두 배가 됩니다.` →
    > - 눈·안개·지형 높이에 따른 착시는 바람에 짝수라 **평균적으로** 지워집니다. 바람받이·풍하 신호는 홀수라 두 배가 됩니다.
    > - 그러나 판정 창(±90 km)이 지형을 자르므로 장면마다 corr(F, h) 와 corr(F_rev, h) 가 ±0.1 까지 다릅니다 [computed]. 우세풍이 한쪽이면 그 몫이 d 에 남습니다(r_h = 0.3 이면 ≤ 0.03).
  - §4.3 끝에 덧붙입니다.
    > - **null 대조(위약, 보고 + 꼬리표, 같은 짝짓기 실행에서 함께)**
    >   - **ρ_even·ρ_odd**: ρ_even = (ρ_res + ρ_rev)/2, ρ_odd = (ρ_res − ρ_rev)/2 이고 둘 다 S∪ 에서 잽니다. 지형 높이 착시는 ρ_even 에, 바람받이·풍하 신호는 ρ_odd 에 모입니다.
    >   - **날짜 바꾸기 ρ_swap·ρ_odd,swap**: 같은 사이트의 다른 판정 날짜 탐측(V_ref·N·H_w·κ·s_rel)으로 만든 ΔC 를 오늘의 T − B 와 짝지어 잽니다. 그런 날짜들의 평균을 씁니다. 같은 사이트에 다른 판정 날짜가 없으면 그 장면은 빠집니다.
    >   - **지형 돌리기 ρ_rot**: DEM 을 관측점 둘레로 180° 돌린 뒤(바다 0 자름도 그 뒤) 같은 탐측·B 로 ΔC 를 만들어 ρ 를 잽니다.
    > - **MODIS 없이 미리 적을 것**: 장면마다 corr_S(F, h_sub), corr_S(F_rev, h_sub), corr_S(ΔC, B) 를 `oro-apply.json` 에 적습니다.
    > - **꼬리표(합격일 때만, 행동은 같음)**
    >   - 중앙 (ρ_odd − ρ_odd,swap) 의 L95 ≤ 0 이면 "그날 탐측이 아니라 사이트의 바람받이 기후 무늬" 로 적습니다.
    >   - \|중앙 ρ_rot\| > 0.03 이면 "null 이 0 이 아님" 으로 적고, 그 값을 c2 옆에 둡니다.
