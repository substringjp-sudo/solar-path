# 고리 대 격자 — 탐색 측정(2026-10-26, 판정 아님)

사용자 질문: "고리 91점 대신 격자로 받는 게 푸리에 계산·좌표 해싱에 낫지 않은가." 답과 숫자는 `docs/SKY_REBUILD_PLAN.md` §166.

- `geom.py` — 표본 배치 정의(현재 고리 `G0`, 고리를 모델 칸에 맞춘 `G0c`, 관측자 중심 균일 `G1`, 세계 고정 균일 `G1a`, 세계 고정 겹 격자 `G2`/`G2b`, 방위 24개 고리 `G4`, 조밀 `G3`). 정식 자를 세울 때 같은 정의를 씁니다.
- `explore-geometry-summary.md` — 복원 충실도(위성 대용 입력, **개발 장면 24 개만**, 날짜 블록 부트스트랩).
- `explore-cache-summary.md` — 이동 시 캐시 재사용·요청 수(기하 모의, 자료 없음).

⚠ 전부 **탐색**입니다. 입력이 위성 대용이라 예보 오차가 없고(실제 예보 고리는 corr50 0.770 → 0.563), held-out 장면은 열지 않았습니다. 정식 판정은 사전 등록한 자(RULER-grid)로.
원자료(JSON 수 MB~수십 MB)와 스크립트는 커밋하지 않았습니다.
