# RULER-shape — 생성 원리에서 세운 구름 뼈대 (적운 계열 · 층적운) — 초안 (검토 전)

**사전 등록**: 이 문서·`shape.py`·`shape-photo-quartiles.json`(shape.py 해시 포함)·`jobs-shape.json`·`eval-shape.sh`·하네스 번들 해시(§10)를 held-out 렌더를
**한 장도 그리기 전에** 커밋합니다. 렌더를 본 뒤 규칙·문턱·장면·판정 코드를 바꾸지 않습니다. 초안은 렌더 전에 독립 비판 3 관점(경계층 기상·측정 통계·셰이더 구현)의
검토를 받고(§1.5) 결함을 고친 뒤 고정합니다.

## 0. 무엇을 왜
사용자(10/15): "모든 구름의 형태를 **각각의 실제 발생 원리**를 기반으로 뼈대를 만들자 — 시각적으로 흔한 모양이 아니라."
지금 무늬(`cloudGenus.ts` FIELDS)는 종류마다 **보기에 그럴듯한 잡음**입니다: 적운은 2.4 km 격자 세포 + 코어 돔 + 터렛 8 + 미세 거품, 층적운은 1.8 km 세포 + 틈 + 덩어리 잡음.
세포 간격·크기·높이·밑면이 **예보의 어떤 값과도 이어져 있지 않고**(응결고도는 §136 물리를 켰을 때 밑면 높이에만), 층 두께는 종류별 상수(적운 1600 m·층적운 750 m)입니다.
§135 의 남은 불만(뾰족한 원뿔, 알갱이, 납작한 렌즈)도 결국 "기둥 높이 d 가 잡음 순위"라서 생깁니다.

현황 조사(§139.0 요약): 셰이더는 층마다 **한 높이 범위**(min/maxLayerHeights)만 알고, 날씨 텍스처의 바이트 d(층당 1 채널)가 종류 단면 hs(hf) 를 통해 **기둥별 꼭대기**를 정합니다
(돔: 구름은 d > 1 − hs(hf) 인 곳, 꼭대기 hf_top = 1 − (1 − d)^(1/top)). 밑면은 모든 기둥이 같습니다(램프 `base`). 즉 "기둥별 꼭대기"는 통로가 이미 있고, 없는 것은
(a) d 를 물리에서 정하는 생성기, (b) 층 밑면·꼭대기 높이를 열역학에서 정하는 계산, (c) **밑면이 변하고 꼭대기가 평평한** 단면(층적운 — 역전층 뚜껑), (d) 전단 기울기입니다.

범위: 이번 자는 **적운(cu)·웅대적운(cg)·층적운(sc)** 만. 고적운·권운·층운·고층운·난층운·적란운은 다음 자(같은 틀, 다른 원리 — 중층 파동/전단, 권운 생성 머리 + 낙하 줄, 역전 아래 안개 들림).

## 1. 후보 — 종류별 발생 원리 → 뼈대 (`cloudSkeleton.ts`, 순수 함수)
입력(모두 앱이 이미 받는 값, `weather.ts` §135.3): 지상 기온·이슬점, 경계층 높이 pblM, CAPE, 기압면 기온 단면, 850/600 hPa 바람. 없으면 적힌 대용값(§1.4).

### 1.1 적운·웅대적운 — 경계층 열기둥
| 원리 | 식 | 출처 |
|---|---|---|
| 밑면 = 응결고도 | z_b = 지면 + 125 m × (T − T_d), 300~3500 m 로 자름(`lclBaseKm` 그대로) | 표준 근사 |
| 경계층 깊이 | h = pblM(있으면), 없으면 z_LCL(얕은 적운은 둘이 비슷) | Thuburn & Efstathiou 2020 |
| 열기둥 간격 | λ = **2√2 × z_LCL**(지면 위), 0.8~8 km 로 자름 | T&E 2020 예측 2.83, 관측 2.7~3.1(Öktem & Romps 2021, SGP 입체 사진 129 일) |
| 구름 폭(중앙값) | w_50 = z_LCL | Öktem & Romps 2021 "폭 ≈ LCL 높이" |
| 크기 분포 | 면적 n(a) ∝ a^(−b), b = 1.7; a_i = a_min·U^(−1/(b−1)), a_min 은 중앙값이 (π/4)w_50² 이 되게, 상한 λ² | Wood & Field 2011 b 1.66 ± 0.04(0.1~1500 km), Savre 2023 범위 1.7~2.4 |
| 높이 ∝ 폭 | D_i = r × w_i. r = 깊이/폭: cu = clamp(D_층/z_LCL, 0.4, 1.2)(humilis 0.5 ~ mediocris 1), cg = clamp(D_층/z_LCL, 1.2, 3)(congestus > 1). D_층 = 예보 저층 덱 두께(있으면), 없으면 cu 0.7 z_LCL · cg 2 z_LCL | 종(species) 정의(humilis 폭 > 높이, mediocris ≈, congestus 높이 > 폭) |
| 층 높이 | H = max_i D_i(가장 큰 열기둥이 층 꼭대기), 기둥 값 d = D_i/H × 열기둥 캡 단면 (1 − ρ²/R²)^½ — 돔 단면(top 1.1)에서 hf_top ≈ d | — |
| 터렛(꽃양배추) | 열기둥 캡 둘레의 거품: 반지름 0.2~0.35 R, 수 6(지금 8·미세 거품 5 는 뺌 — 알갱이 원인 후보) | 열기둥 혼입(entrainment) 거품 |
| 운량 | 열기둥 자리는 λ 간격 격자 + 지터 0.9; 큰 것부터 Σ π(w_i/2)² / 타일² ≈ cover 가 될 때까지 켬. Σ 전체 < cover 면 폭을 √(cover/Σ) 배(≤ λ — 합쳐져 층적운 꼴), 그 위는 `growBeyondCapacity` | 위에서 본 면적 = 운량(§127 과 같은 약속) |
| 전단 기울기(K2) | 꼭대기 수평 밀림 = D × Δu_D / w_up, Δu_D = S·D, S = |V_600 − V_850| / 2.7 km, w_up = 2 m/s, 밀림 ≤ 1.5 D, 방향 = 전단 벡터 | 열기둥이 D 를 오르는 동안 전단으로 밀림 |

### 1.2 층적운 — 역전층 아래 뒤집힌 대류
| 원리 | 식 | 출처 |
|---|---|---|
| 꼭대기 = 역전층 | z_i = 밑면 위 첫 안정층(기압면 기온 단면에서 감률 < 2 K/km 인 첫 구간의 아래 면), 밑면 위 3 km 안에 없으면 밑면 + 600 m | 층적운 = 역전 뚜껑 아래 혼합층 |
| 밑면 | 예보 덱 밑면(있으면) 아니면 z_LCL; 두께 = z_i − 밑면, 200~1200 m 로 자름 | — |
| 단면 | **뚜껑 모드**(새 genusMode 2): 꼭대기 평평(hf 1 = z_i), 기둥 값 d 가 작을수록 밑면이 높음 — 구름은 hf > 1 − d, 밑면 가장자리 `edge` 로 부드럽게 | 층적운은 위가 평평하고 밑이 울퉁불퉁(LWP 변동) |
| 혼합층 세포/롤 | 요소 간격 λ_el = 2.5 h(h = z_i − 지면), 롤: |V_850| ≥ 5 m/s 면 바람 방향으로 3:1 늘임(각도 바람 ±0°), 아니면 등방 세포 | 롤 종횡비 2~4(Etling & Brown 1993) |
| 중규모 닫힌 세포 | λ_meso = min(35 h, 타일 24 km); 세포 가운데 두껍고 가장자리 얇음(코사인 덮개) — 운량 < 1 이면 가장자리부터 비움 | 닫힌 세포 종횡비 30~40(Wood & Hartmann 2006; Monnier 2026) |
| 장 → d | f = 중규모 덮개 × (0.6 + 0.4 × 요소 세포) × (1 + 0.15 잡음) → 운량 분위수 문턱(지금 경로 그대로) → d = 두께 순위 | 운량 약속 유지 |

### 1.3 후보 표
| 후보 | 바꾸는 것 | 무엇을 가르나 |
|---|---|---|
| **K0** | 지금(FIELDS·GENUS 높이 상수) | 기준 |

### 1.4 대용값(입력이 없을 때)
pblM 없음 → h = z_LCL · 기압면 기온 없음 → z_i = 밑면 + 600 m · 바람 없음 → 전단 0, 등방 세포 · 이슬점 없음 → 밑면 = 예보 덱 밑면(지금과 같음), z_LCL 대신 (밑면 − 지면).

## 4. 판정 규칙(렌더 전 고정)
종류별 칸 = 지표(§2) × 장면 × 방위(cu: 8 지표 × 2 × 3 = 48, cg: 8 × 1 × 3, sc: 6 × 2 × 3 — baseTopRough 는 sc 에 안 씀; sc 의 사진은 StSc 묶음).
- **inside** = 칸 값이 사진 [q25, q75] 안, **wide** = [q10, q90] 안. 무효 칸(§2)은 둘 다 아님(후보 사이 무효 수도 보고).
- **S(합격, 종류별)**: inside 수 ≥ K0 inside 수 + 2 **그리고** wide 수 ≥ K0 wide 수. 세 종류 중 **둘 이상** 합격이고 나머지 하나가 K0 보다 inside 가 적지 않으면 후보 채택.
- **P(짝 비교, 보고)**: 같은 칸에서 |후보 − q50| < |K0 − q50| 인 칸 수(개선) / 반대(악화). 특히 baseTopRough(cu·cg)·nnSpacing 은 따로 적음 — 뼈대의 서명.
- 가드: **G1** CLIP 라벨(`clip-labels.py`): cu 장면에서 Cu 라벨 수(3 방위), sc85 에서 층 묶음 라벨 수가 K0 보다 적지 않음. **G3** 끄면 그대로: 날씨 타일 md5(개발 장면 3 + 합성 5), 셰이더 글자, 상태 해시 — 모두 K0 과 동일. **G4** 하늘 평균 면적(알파 ≥ 0.15): |Δ| > 5 %p 면 "운량 역표 재측정 필요"로 표시(§127 표가 옛 무늬에 맞춘 것 — 뼈대 거부 사유가 아님, 다음 일로 기록). **G5** 셰이더 시간: K2 의 프레임 시간이 K0 의 1.3 배를 넘으면 K2 는 "비용 때문에 보류".
- 최종 판정은 사용자의 눈(RULER.md). 판정기와 눈이 다르면 눈을 적고, 숫자는 그대로 둡니다.

## 5. 조건부 읽기(미리)
- K1 S 통과 + K2 추가 개선 없음 → K1 채택, 전단은 보류(비용).

- G4 넘김 → 운량 역표(RULER-cover) 재측정이 뼈대 채택의 선행 조건.

- 열기둥 자리를 λ 격자 + 지터로 두는 것은 구름 거리(cloud street)·세포 조직화(§130 흐름)를 안 담음 — 흐름 모형과의 결합은 다음 자.

- 층적운 중규모 세포는 타일(24 km)보다 커서 한 세포만 들어감 — 운량 가장자리 패턴이 주기적으로 되풀이됨(알려진 모양 결함, 측정엔 영향 적음).
- areaExp 는 화면 원근 때문에 위에서 본 b 와 다름 — 사진과 같은 조건에서만 의미.
