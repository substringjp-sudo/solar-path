## 0. 무엇을 왜
사용자(10/15): "모든 구름의 형태를 **각각의 실제 발생 원리**를 기반으로 뼈대를 만들자 — 시각적으로 흔한 모양이 아니라."
지금 무늬(`cloudGenus.ts` FIELDS)는 종류마다 **보기에 그럴듯한 잡음**입니다: 적운은 2.4 km 격자 세포 + 코어 돔 + 터렛 8 + 미세 거품, 층적운은 1.8 km 세포 + 틈 + 덩어리 잡음.
세포 간격·크기·높이·밑면이 **예보의 어떤 값과도 이어져 있지 않고**(응결고도는 §136 물리를 켰을 때 밑면 높이에만), 층 두께는 종류별 상수(적운 1600 m·층적운 750 m)입니다.

현황(§139.0): 셰이더는 층마다 **한 높이 범위**만 알고, 날씨 바이트 d(층당 1 채널)가 종류 단면 hs(hf) 를 통해 기둥별 꼭대기를 정합니다(돔: 구름은 d > 1 − hs(hf), hf_top = 1 − (1 − d)^(1/top)).
그러나 밀도 자체가 d·edge 에 비례해(검토 구현 6) d 가 작은 기둥은 모양 잡음에 지워집니다 — 뾰족한 원뿔·알갱이(§135)의 유력한 원인. 없는 것은 (a) d 를 물리에서 정하는 생성기,
(b) 층 밑면·꼭대기를 열역학에서 정하는 계산, (c) 밑면이 변하고 꼭대기가 평평한 단면(층적운), (d) 봉투 거리 밀도, (e) 전단 기울기(흐름 S4 레인 재사용).

범위: **적운(cu)·웅대적운(cg)·층적운(sc)** 만. 다른 종류는 다음 자(같은 틀, 다른 원리).

## 1. 후보 — 종류별 발생 원리 → 뼈대 (`cloudSkeleton.ts`, 순수 함수)
입력(앱이 이미 받는 값): 지상 기온·이슬점, pblM, CAPE, 영하고도, 기압면 기온·상대습도 단면, 850/600 hPa 바람(**m/s**, 동·북), 강수. 없으면 §1.3 대용값. 모든 길이는 지면 위(AGL) 로 셈.

### 1.1 적운·웅대적운 — 경계층 열기둥
| 원리 | 식 | 출처 |
|---|---|---|
| 밑면 = 응결고도 | z_b = 125 m × (T − T_d), 150~3500 m | Espy/Lawrence 2005 ±5 % |
| 간격 | λ = 2√2 × min(pblM, z_b), 0.5~10 km | Thuburn & Efstathiou 2020(건조 혼합층 깊이), Öktem & Romps 2021 관측 2.7~3.1(밑면 높이 대리) |
| 폭 중앙값 | w_50 = **0.6 z_b**(불확실 ±0.2 — SGP 코드 길이 0.5~1 km / LCL 1~2 km) | SGP 지상 통계 |
| 크기 분포 | 면적 n(a) ∝ a^(−b), b = 1.7; 절단 파레토 a = a_min[1 − U(1 − (a_min/a_max)^(b−1))]^(−1/(b−1)), a_max = (0.6 λ)², a_min 은 중앙값이 (π/4) w_50² 이 되게 수치로 | Zhao & Di Girolamo 2007 1.7~1.8, Neggers 2003 LES ≈ 1.7 |
| 깊이 | D_i = min(r_i w_i, D_max), r_i = r_50 (w_i/w_50)^0.3; r_50: cu = clamp(D_max/z_b, 0.4, 1.2), cg = clamp(D_max/z_b, 1.2, 2). D_max: 예보 덱 두께 → (z_i − z_b)(§1.2 의 z_i) → cu 0.7 z_b; cg 는 영하고도 − z_b(≥ 2500 m) | humilis 폭 > 높이 ~ congestus 높이 > 폭; 꼭대기는 역전/LNB |
| 층 | 밑면 z_b, 높이 H = D_max. 기둥 값 d = (D_i/H)·(1 − ρ²/R_i²)^p, p = 0.5/r_i | — |
| 활성 열기둥 | 자리 = λ 격자 + 지터 0.9(§1.4); 롤 조건(§1.2)이면 바람 방향 줄(구름 거리). 켤 확률 ∝ a_i^0.5 (결정적 시드) 로 Σ π(w_i/2)² / 타일² ≈ cover(±3 %) 가 될 때까지. 전부 켜도 모자라면 폭을 √(cover/Σ) 배(≤ 0.6 λ — 합쳐지는 체제), 그래도 모자라면 생성기 안 **스커트**(세포 둘레 거리 d = 0.08·(1 − dist/0.3λ)) | 위에서 본 면적 = 운량 — **coverRemap 미적용**(원 운량) |
| 전단 기울기(K2) | 밀림 = S·D²/(2 w_up), S = |V_600 − V_850| / 2.7 km, w_up cu 2 · cg max(3, 0.3√(2·CAPE)) m/s, ≤ 1.5 D, 방향 = 전단 벡터; tilt = 밀림/D | 선형 전단 속을 D 만큼 오르는 열기둥 |

### 1.2 층적운 — 역전층 아래 뒤집힌 대류
| 원리 | 식 | 출처 |
|---|---|---|

| 밑면 | 예보 덱 밑면 → 첫 RH ≥ 90 % 면 → z_b(LCL); 두께 = z_i − 밑면, 200~1200 m | 분리 경계층에서 LCL 과소(Jones 2011) |
| 단면 | **뚜껑 모드**(genusMode 3): 꼭대기 평평(hf 1 = z_i), 구름은 hf > 1 − d, 밀도 = clamp((hf − (1 − d))·8), hs(1) = 0 가드, domePow 0.5(중앙값 밑면 0.3 H), densityProfile 평평 | 위 평평·밑 울퉁(LWP) |
| 혼합층 세포/롤 | h = z_i, λ_el = 2.5 h(±1 h); 롤: |V_850| ≥ 5 m/s 면 바람 −15° 방향 3:1, 아니면 등방 | Etling & Brown 1993 종횡비 2~4 |
| 중규모 세포 | 봉우리 35 h 의 타일 주기 저주파 잡음(2 옥타브); **열린**(cover < 0.6 또는 강수 > 0: 덮개 = 1 − 코사인, 고리 폭 0.2 λ_meso) / **닫힌**(≥ 0.6: 코사인 덮개) | Wood & Hartmann 2006 AR ≈ 40, 열린 0.4~0.6 · 닫힌 0.8~1 |
| 장 → d | f = 덮개 × (0.6 + 0.4 요소) × (1 + 0.15 잡음) → 운량 분위수 문턱(coverRemap 미적용) → d = 순위^0.5 | 운량 약속 |

### 1.3 대용값
pblM 없음 → λ 척도 z_b, z_i 는 (2)~(4) · 기압면 없음 → z_i 밑면 + 600 m · 바람 없음 → 전단 0, 등방 · 이슬점 없음 → 밑면 = 예보 덱 밑면, z_b 대신 (밑면 − 지면) · CAPE 없음 → w_up cg 3 · 영하고도 없음 → cg D_max 2500 m.

## 4. 판정(렌더 전 고정)
- 칸 = 지표 × 장면 실현(장면 × 시드) × 방위, **V** = 기준(K0h)·후보 둘 다 유효한 칸. inside = 사진 [q25, q75], wide = [q10, q90]. 문턱 세 벌: 기본(점 추정)·넓게(CI 바깥)·좁게(CI 안쪽).
- 여유 m = max(3, max_s |inside(K0h_s) − inside(K0h)| + 1), s = 영가설 시드 7171·8181(같은 V 위).
- **S(종류별)**: 세 벌 모두에서 inside(후보) ≥ inside(K0h) + m **그리고** wide(후보) ≥ wide(K0h) **그리고** 연속 점수 z = |v − q50|/(q75 − q25) 의 중앙값 차(K0h − 후보)의 뷰 클러스터 부트스트랩 90 % CI 하한 > 0. 기본 벌만 성립 = 불확정.
- **1 차 가설**: cu 에서 K1 S 통과. **채택** = cu S 통과 ∧ sc 에서 K1 의 inside ≥ K0h 의 inside(기본 벌) ∧ 눈 체크리스트 ≥ K0h. sc S·cg·K2 는 2 차(보고). K2 는 K1 이 채택될 때만 "K1 대비" 로 읽음.
- **P(보고)**: 칸별 |후보 − q50| vs |K0h − q50| 개선/악화/동률(|Δ| < 0.1 IQR), 군별 1 표, baseTopRough·nnReg 따로. K0 대비도 보고.
- 가드: **G1** CLIP(`clip-labels.py`): cu 장면 Cu 라벨 수, sc85 층 묶음 라벨 수가 K0h 보다 적지 않음. **G3** 끄면 그대로: 날씨 타일 md5(개발 3 + 합성 9)·셰이더 글자·상태 해시 K0 동일. **G4** 장면 |Δ cloudFrac(알파)| > 5 %p → 그 장면 조각 칸 양쪽 무효(V 에서 뺌) + "역표 재측정 필요" 기록. **G5** K2 프레임 시간(N ≥ 5 중앙값, 같은 장면) ≤ 1.3 × K1.
- 눈 체크리스트(방위별 ○/×, 렌더 전 고정): ① 뾰족한 원뿔 없음 ② 알갱이 점 없음 ③ 밑면이 평평(cu)/꼭대기 평평·밑면 변동(sc) ④ 크기가 섞여 있음(한 크기 반복 아님).

## 5. 조건부 읽기(미리)
- K1 채택 + K2 가 K1 보다 inside 적지 않고 G5 통과 → K2 까지; 아니면 K1.
- cu 불합격·P 에서 baseTopRough·nnReg 개선 → 서명은 맞고 크기 분포(a_min·b)·자유 매개변수(§1.4)만 다음 자.
- cu 합격·sc 악화 → 뚜껑 모드 vs 세포 간격 ablation 은 다음 자(이번엔 안 고침).
- G4 넘김 → 운량 역표 재측정이 채택의 선행 조건.
- K0h 가 K0 보다 inside 가 많으면 "층 고도만으로도 개선" 을 따로 적음(뼈대 몫과 분리).
