## 2. 새 G2 하늘 조항(G2s)
- **행** = 옛 G2 와 같은 F-std 창 평균 행(장면 × 방위 t·s·a, record 장면 제외).
- **마스크** S = (α_B < 0.02) ∧ (α_E < 0.02) ∧ (화소 고도 > 0°). α 는 `mean.alpha.png`/255, 고도는 `grain.pixel_elevation(W, H, el, vfov)`(잡 입력의 카메라 기울기·시야각, 굴림 없음).
- **행 값** d = \|ln(median_S L_E / median_S L_B)\|, L = `fm.luminance`(옛 photo_metrics 와 같은 선형 휘도). \|S\| < 200 화소면 행 무효.
- **장면 값** = 유효 행 d 의 방위 중앙. 유효 행이 없는 장면은 빠집니다.
- **통과** = 유효 장면 ≥ 24 그리고 장면 값 ≤ 0.01 인 장면 비율 ≥ 0.90 그리고 장면 값 최대 ≤ 0.02. 유효 장면 < 24 → 평가 불가(가드 미평가 → 채택 안 함).
- **G2 전체** = G2s ∧ 옛 구름 조항(장면 비율 ≥ 0.9 · 최대 ≤ 0.30) ∧ 옛 포화 조항(≤ 0.01). 구름·포화 값은 옛 게이트 파일의 값 그대로.
- 뜻: 공유 마스크는 구름 ↔ 하늘 소속이 바뀐 화소를 뺍니다 — 그 화소는 구름 변화이고 G1(면적)·G2 구름 조항·G5 가 봅니다. 하늘 렌더(노출·대기·연무)가 바뀌면 공유 마스크 화소 전체가 같이 움직여 잡힙니다.

## 3. 새 G3(CLIP 종류 라벨)
- **그림** = 옛 G3 와 같은 12 장: ac60·ci60 × e20·e45 × t·s·a 의 F-std `mean.png`, B·E 둘 다.
- **점수**: 그림마다 **따로(묶음 1)**, K = 16 개 떨림 복사본. 복사본 k 는 각 화소·채널에 {−1, 0, +1} 정수 잡음(`numpy.random.default_rng(1000 + k)`, 같은 확률)을 더하고 [0, 255] 로 자른 그림. 동결 판정기 `clip/judge2.py` 의 `prep(top 0.78)` → 시각 모델 → 정규화 → `probs`(T = 100, `class_embeds('genus')`). 16 개 확률 벡터의 평균 → **라벨 = argmax**. 맞음 = 옛 `clip-labels.py` 와 같은 집합(AcCc → {AcCc}, Ci → {Ci, Cs}).
- **장면 값** h = 맞는 방위 수(0~3). 여백 ln(p_맞음 최대 / p_그 밖 최대) 은 기록.
- **통과** = 모든 장면에서 h_E ≥ h_B − 1 그리고 Σh_E ≥ Σh_B − 1(네 장면 합). 그림이 하나라도 없으면 평가 불가.
- 뜻: 떨림 평균은 양자화 혼돈을 고르게 하고, 묶음 1 은 그림끼리 엮임을 없앱니다. 허용 1 은 평균 뒤에도 남는 경계 근처 한 장의 뒤집힘을 위한 것입니다.
