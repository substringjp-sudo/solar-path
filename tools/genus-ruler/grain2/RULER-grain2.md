## 1. 왜 바꾸나(감사 요약)
- **G2 하늘**: 옛 정의는 그림마다 따로 잡은 전체 화면 마스크(알파 < 0.02)의 중앙 휘도를 비교하고, 행 108 개의 최댓값이 0.01 을 넘으면 실패입니다. 이 마스크에 지평선 아래 검은 땅이 들어가(17/108 행에서 ≥ 50 %) 구름 테두리 알파가 조금 바뀌면 중앙값이 땅 쪽으로 넘어갑니다. 하늘 화소 값은 바뀌지 않았고(공유 마스크에서 화소별 ln 비 중앙 0.0000, 97/97 행), C0 끼리도 0.013~0.038 로 걸립니다.
- **G3**: C0 의 ci60_e45 라벨 셋은 여백 +0.09~0.12 logit 위에 섭니다. int8 동적 양자화 CLIP 이 3 장 묶음에 엮여 ±1 LSB 떨림만으로 라벨이 바뀝니다(C0 를 떨게 한 21 번 중 셋 다 맞은 것 1 번). A/A 허용폭이 없습니다. 감사가 본 실제 변화도 있습니다: R1 E1a.0 의 ci60_e45 a 여백 0.85 → −0.09(5~6 SD).
- 두 가드는 화소를 바꾸는 팔이면 좋아지든 아니든 거의 늘 실패합니다(A/A 기준 통과 확률 G2 하늘 ≲ 0.11, G3 ≈ 0.14).

## 2. 새 G2 하늘 조항(G2s)
- **행** = 옛 G2 와 같은 F-std 창 평균 행(non-record 장면 × 방위 t·s·a = 108). 잡이 없거나 captureOk 가 아니면 '빠진 행' → G2s 평가 불가.
- **고도** = `grain.pixel_elevation(W, H, el, vfov, 자른 행)`. 화소 고도 > 0° 만 하늘로 봅니다(0 ~ −0.33° 의 굽은 지평선 띠도 일부러 뺌).
- **범위**: 행은 \|알파_B < 0.02 ∧ 고도 > 0\| ≥ 200 **또는** \|알파_E < 0.02 ∧ 고도 > 0\| ≥ 200 이면 범위 안(그렇지 않으면 온통 구름 — 빠짐 아님, 범위 밖).
- **휘도 값** d: 공유 하늘 S = (알파_B < 0.02) ∧ (알파_E < 0.02) ∧ (고도 > 0). \|S\| < 200 이면 d = 실패 값(상한에서 실패 — 하늘이 사라진 행을 빼지 않음). 아니면 고도 띠 (0,5]·(5,15]·(15,90]° 마다(띠 화소 ≥ 200) \|ln(평균_띠 L_E / 평균_띠 L_B)\| 의 최대(셀 띠가 없으면 S 전체 평균의 비). L = `fm.luminance`(선형). S 의 중앙값 비는 기록만.
- **소속 값** m: O_X = (알파_X < 0.02) ∧ (고도 > 0) ∧ (알파_X ≥ 0.02 화소에서 8 화소 넘게 떨어짐). 잃음 = \|O_B ∧ 알파_E ≥ 0.02\| / \|O_B\|(\|O_B\| ≥ 200 일 때), 얻음 = 같은 식을 B·E 바꿔. m = 둘의 최대.
- **장면 값** = 범위 안 행들의 **방위 최대**(d 와 m 따로).
- **통과** = (휘도) 유효 장면 ≥ 24 ∧ 장면 값 ≤ 0.01 인 비율 ≥ 0.95 ∧ 최대 ≤ 0.02, 그리고 (소속) 장면 ≥ 24 ∧ ≤ 0.02 인 비율 ≥ 0.90 ∧ 최대 ≤ 0.05. 행 빠짐·장면 모자람 → 평가 불가(가드 미평가 → 채택 안 함).
- **G2 전체** = G2s ∧ 옛 구름 조항(장면 비율 ≥ 0.9 · 최대 ≤ 0.30) ∧ 옛 포화 조항(≤ 0.01). 구름·포화가 실패면 실패, 아니면 G2s 의 값(None 이면 None).
- **뜻**: 공유 마스크는 구름 ↔ 하늘 소속이 바뀐 테두리 화소를 휘도 값에서 뺍니다(그 화소는 G1·G2 구름·G5 가 알파 ≥ 0.15 에서 봄). 알파 [0.02, 0.15) 로 옮겨 가는 열린 하늘(얇은 막·연무 같은 변화)은 **소속 값만** 지킵니다. 잡는 꼴: 전체·고도 띠·한 방위의 하늘 밝기 변화, **구름 바로 옆(알파 < 0.02) 화소의 밝기 고리**(공유 하늘에 들어 있음 — 2 화소 고리 × 1.10 이 C0 에서 장면 값 0.067; (0,5]° 띠는 공유 하늘의 약 절반이 구름 옆 화소), 열린 하늘의 얇은 막, 하늘이 사라지는 행. 못 잡는 꼴: 구름에서 8 화소 안의 알파 < 0.02 → [0.02, 0.15) 소속 변화(§6).

## 3. 새 G3(CLIP 종류 라벨)
- **그림** = 옛 G3 와 같은 12 장: ac60·ci60 × e20·e45 × t·s·a 의 F-std `mean.png`, B·E 둘 다. 하나라도 없으면(captureOk 아님 포함) 평가 불가.
- **점수**: 그림마다 **따로(묶음 1)**, **한 코어**(`taskset -c 3`; 스레드 수가 결과에 닿지 않게, affinity 를 clipCfg 에 기록), K = 16 떨림 복사본(각 화소·채널에 {−1, 0, +1}, `numpy.random.default_rng(1000 + k)`, [0, 255] 로 자름). 동결 판정기 `clip/judge2.py` 의 `prep(top 0.78)` → 시각 모델 → 정규화 → `probs`(T = 100, `class_embeds('genus')`). 16 확률(float64 로 바꿔 캐시와 같은 수)의 평균 → 라벨 = argmax. 여백 m = ln(p_맞음 최대 / p_그 밖 최대)(m > 0 ⇔ 맞음). 복사본별 여백의 표준오차 se 와 경계 표지(\|m\| < 2·se)는 기록.
- **규칙**: 잃은 그림 = B 맞음 → E 틀림. **종류(AcCc · Ci)마다** 잃은 그림이 없거나, 하나이고 그 그림의 B 여백 m_B ≤ δ 이면 통과. 두 종류 모두 통과여야 G3 통과. **얻은 그림은 잃은 그림을 메우지 않습니다**(장면·방위·종류 사이 모두).
- **δ** = max(0.30, A/A 세 쌍 × 12 그림의 최대 \|m_E − m_B\|). δ > 0.60 이면 동결하지 않습니다. 값은 `aa` 단계가 `g3-near.json` 에 쓰고 동결 커밋에 들어갑니다.
- **뜻**: 떨림 평균은 양자화 혼돈을 고르게 하지만 렌더 씨앗 사이 분산은 없애지 않습니다 — 그것은 δ 와 §4 의 P_FF 가 맡습니다. 한 종류를 통째로 바꾸거나 강한 맞음(여백 > δ)을 잃으면 실패합니다.
