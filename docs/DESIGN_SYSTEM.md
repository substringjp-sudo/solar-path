# 디자인 언어 (2026-09-29 정리)

사용자 요청: "앱 전체 레이아웃과 프레임, 매터리얼, 색조합, 디자인언어, 정보재배치, ui 인터페이스를 정리하자 … 사용자가 뭘 어디서 보고 어디서 컨트롤해야 할지."

값의 출처는 `src/theme/tokens.ts` 한 곳입니다. 공용 부품은 `src/components/ui/`에 있습니다. 새 화면을 만들 때는 이 두 곳의 값만 씁니다.

## 1. 어디서 보고, 어디서 조작하나 (자리 규칙)

하늘 탭과 지도 탭은 같은 자리 규칙을 따릅니다.

| 자리 | 하는 일 | 하늘 탭 | 지도 탭 |
|---|---|---|---|
| 헤더 1줄 | 앱 전체 — 탭 · 위치 · 설정 | `01 하늘 · 02 지도 · 03 기록`, 📍, ⚙ | 같음 |
| 헤더 2줄 | 앱 전체 — 날짜 | ‹ 날짜 ›, 시간대 | 같음 (지도도 헤더 날짜를 따름) |
| 화면 왼쪽 위 | **읽기** | 방위 눈금 HUD | 태양 배지(고도·방위·일출·일몰) |
| 화면 오른쪽 위 | **보기 조작** | 레이어 | 위치(⌖) · 구/지도 · 도움말 |
| 화면 왼쪽 아래 | **범례 · 읽기값** | (오류·진행 띠) | 범례, 구름 읽기값 |
| 아래 도킹 패널 | **시간 조작 + 주 동작** | 시간 슬라이더 · 실시간 · 촬영 | 절기 · 날짜 · 시각 슬라이더 · 재생 |
| 끌어올리는 시트 | **판단 → 언제 → 근거** | 노을 예측 → 이벤트 → 태양·달 수치 | — |

- 시트 순서를 바꿨습니다. 전에는 예측 → 수치 → 이벤트였습니다. 이제 "좋을까?(예측)" 다음에 "언제?(이벤트)"를 보고, 수치는 근거로 맨 아래에 둡니다.
- 설정 순서도 바꿨습니다. 전에는 계정 → 언어 → 권한 → 앱 정보였습니다. 이제 언어 → 권한 → 계정 → 앱 정보 순이고, 개발자 옵션은 개발 빌드에서만 맨 아래에 나옵니다. 자주 바꾸는 것을 위에 두었습니다.

## 2. 색은 역할로 고릅니다

| 역할 | 토큰 | 값 | 쓰는 곳 |
|---|---|---|---|
| 누를 수 있는 것 · 고른 것 | `accent` | #38BDF8 | 선택된 탭, 켜진 칩, 슬라이더 채움과 손잡이 글자, 주 버튼(재생 · 로그인) |
| 해 · 노을 데이터 | `sun` · `glow` | #FBBF24 · #F97316 | 해 아이콘, 일출·일몰 시각, 노을 점수 |
| 달 데이터 | `moon` | #A5B4FC | 달 아이콘(시트, 이벤트) |
| 구름 데이터 | `cloud` | #E2E8F0 | 구름 읽기값 |
| 상태 | `success` · `warning` · `danger` | | 권한 허용/거부, 오류, 재생 중 정지 |
| 글자 | `text` · `textDim` · `textMute` | | 본문 · 설명 · 단위 |

- 전에는 강조색이 낮에는 주황, 밤에는 하늘색으로 바뀌었습니다. 그래서 "누를 수 있는 것"의 색이 시간대마다 달랐습니다. 이제 강조색은 늘 하늘색입니다.
- 주황은 노을 데이터에만 씁니다.
- 이벤트 탭 아이콘도 이 규칙을 따릅니다. 전에는 "추천" 탭이 주황이었는데, 이제 선택된 탭은 하늘색입니다.
- 초승달·월출 아이콘은 하늘색에서 달 색으로 바꿨습니다.

## 3. 재질

| 재질 | 토큰 | 쓰는 곳 |
|---|---|---|
| 바닥 | `color.bg` | 앱 배경 |
| 도킹 패널 | `material.panel` (불투명) | 아래 조작부, 시트, 설정 카드 |
| 떠 있는 것 | `material.overlay` (반투명 82%) | 3D·지도 위의 버튼, 배지, 범례 |
| 창 | `material.modal` + `color.scrim` | 설정, 레이어, 위치 창 |

- 떠 있는 버튼은 두 탭 모두 32px 한 변에 같은 재질을 씁니다(`OVERLAY_BTN`).
- 전에는 하늘 레이어 버튼만 따로 검은 반투명이었고, 지도 버튼은 불투명 카드색이었습니다.

## 4. 글자 · 모서리 · 간격

- 글자는 다섯 단계입니다: `micro 9 · label 11 · body 13 · title 16 · display 22`. 수치와 라벨은 모노 글꼴입니다.
- 모서리는 `xs 4 · sm 6 · md 10 · lg 16 · pill`입니다.
- 간격은 `2 · 4 · 8 · 12 · 16 · 24`입니다.

## 5. 공용 부품 (`src/components/ui`)

- `OverlayButton`: 떠 있는 아이콘 버튼. `active`이면 강조 재질이 됩니다.
- `Chip`: 켜고 끄는 작은 선택 버튼.
- `SectionLabel`: 패널 안 구획 머리.
- `Panel`: 도킹 패널 카드.

## 6. 이번에 한 것과 남은 것

- 화면 부품 15개의 StyleSheet 값을 토큰으로 옮겼습니다(헤더, 시간 슬라이더, 하늘, 시트, 카드, 레이어 창, 지도 넷, 설정, 갤러리, 사진 상세, 위치 창, 슬라이더).
  - 모서리 반경: 서로 다른 값 17가지 → 토큰 5개. 토큰 밖 값은 1 · 4 · 8 · 28 넷만 남았습니다(점 · 손잡이 같은 모양 값).
  - 색 리터럴: 388곳 → 245곳.
- 지도 슬라이더 손잡이를 하늘 탭과 같게 바꿨습니다. 전에는 흰 상자에 검은 글자였고, 이제 어두운 상자에 강조색 글자입니다. 손잡이가 위 라벨 줄을 덮던 것(`· 23:17 UTC`가 가려짐)도 14px를 비워 고쳤습니다.
- **남은 것**
  - 색 리터럴 245곳이 남아 있습니다. 대부분 데이터 색입니다(등시선, 행성, 절기 점, 타임라인 마커, 노을 품질 색표). 역할 토큰으로 옮길지는 한 곳씩 따져야 해서 기계적으로 바꾸지 않았습니다.
  - 촬영 화면(SunCamera)은 웹에서 돌지 않아 눈으로 확인할 수 없어 옮기지 않았습니다.
  - 공용 부품은 아직 새 코드에서만 씁니다. 기존 버튼을 부품으로 바꾸는 일은, 지도 버튼 자리 상수(`locationPick.topButtonsWidth`)와 엮여 있어 다음으로 미뤘습니다.
