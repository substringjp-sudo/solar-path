# BeforeGlow 디자인 언어

이 문서는 앱의 모든 화면이 따르는 공통 규칙입니다. 새 화면이나 부품을 만들 때, 혹은 기존 화면을 고칠 때 이 문서를 먼저 봅니다.

- 값은 `src/theme/tokens.ts` 한 곳에서만 정합니다.
- 움직임 도우미는 `src/theme/motion.ts`에 있습니다.
- 공용 부품은 `src/components/ui/`에 있습니다.
- 여기 적힌 규칙과 코드가 다르면 코드를 고칩니다. 규칙을 바꿔야 한다면 이 문서를 먼저 고칩니다.

정리한 날: 2026-09-29 ~ 09-30. 사용자 요청: "앱 전체 레이아웃과 프레임, 매터리얼, 색조합, 디자인언어, 정보재배치, ui 인터페이스를 정리하자", "공통적인 디자인 언어를 명문화해보자. 리액션 애니메이션까지 해서."

---

## 0. 원칙 다섯 가지

1. **하늘이 주인공입니다.** UI는 하늘(3D 장면, 지도)을 가리지 않도록 어둡고 반투명하게, 가장자리에 둡니다. 가운데를 차지하는 것은 사용자가 불러낸 창뿐입니다.
2. **색은 뜻입니다.** 하늘색은 "누를 수 있음·고름"이고, 주황은 "노을 데이터"입니다. 꾸밈으로 색을 쓰지 않습니다(§2).
3. **자리가 역할을 말합니다.** 읽는 것과 조작하는 것은 늘 같은 자리에 있습니다. 탭이 바뀌어도 자리는 그대로입니다(§5).
4. **판단 → 언제 → 근거 순으로 보여 줍니다.** "좋을까?"가 먼저, "몇 시?"가 다음, 수치는 맨 아래입니다.
5. **움직임은 대답입니다.** 눌렀다, 바뀌었다, 나타났다를 알려 줄 만큼만 움직입니다. 장식으로 움직이지 않습니다(§8).

## 2. 색 — 역할로 고릅니다

| 역할 | 토큰 | 쓰는 곳 | 쓰지 않는 곳 |
|---|---|---|---|
| **누를 수 있음 · 고름** | `accent` · `accentSoft` · `accentLine` | 선택된 탭·칩·줌 배율, 켜진 토글, 슬라이더 채움, 주 버튼(재생·로그인), 링크 | 장식, 데이터 값 |
| **해 · 노을** | `sun` · `glow` | 해 아이콘, 일출·일몰 시각, 노을 점수, 촬영 화면의 일출·일몰 상태 | 버튼 바탕, 선택 표시 |
| **달** | `moon` | 달 아이콘(시트·이벤트·레이어) | |
| **구름** | `cloud` | 구름 읽기값, 구름 레이어 아이콘 | |
| **상태** | `success` · `warning` · `danger` | 권한 허용/거부, 오류 띠, 재생 중의 "멈춤" | 꾸밈 |
| **글자** | `text` · `textDim` · `textMute` | 본문 · 설명과 보조 값 · 단위와 꺼진 것 | |

- **강조색은 하나입니다.** 전에는 낮에 강조색이 주황으로 바뀌었습니다. 이제 시간대와 상관없이 하늘색입니다.
- **주 버튼 글자는 `onAccent`입니다.** 어두운 모드에서는 아주 어두운 남색(하늘색 위에서 흰 글자는 대비가 모자람), 밝은 모드에서는 흰색(진한 하늘색 `#0369A1` 위 5.9:1)입니다.
- **흰 바탕 버튼은 쓰지 않습니다.** 예전 로그인 버튼과 지도 슬라이더 손잡이가 흰 상자였습니다.
- **순수 검정(`#000`)은 두 곳에만 씁니다:** 그림자(`shadowColor`)와 카메라 미리보기 바탕.

## 3. 데이터 색 — 그림과 범례가 같은 값

`dataColor`는 값 자체가 뜻을 가집니다. 지도에 그린 일출선이 `dataColor.sunrise`이면 범례, 절기 점, 시간 슬라이더의 일출 표시도 모두 `dataColor.sunrise`여야 합니다. 그래서 역할색으로 바꾸지 않고 **값을 그대로 둔 채 이름만 붙였습니다.**

| 무리 | 이름 | 값 | 그리는 곳 → 설명하는 곳 |
|---|---|---|---|
| 해 출몰선 | `sunrise` · `sunset` | #FFA500 · #FF4500 | MapGlobe·MapCanvas의 선 → 지도 범례, 시간 슬라이더 마커, 태양 배지 |
| 가까운 축척 | `altitude` · `azimuth` | #38BDF8 · #FB923C | 고도선·방위선 → 지도 범례 |
| 절기 | `spring` · `summer` · `autumn` · `winter` | #4ADE80 · #FFA500 · #F97316 · #38BDF8 | 날짜 슬라이더 점 → 절기 버튼 점 |
| 3D 레이어 | `stars` · `milkyway` · `planets` · `cityLights` · `paths` | #A78BFA · #C4B5FD · #F43F5E · #F59E0B · #22C55E | 레이어 창 아이콘, 별 밝기 슬라이더 |
| 노을 예보 | `qEpic` · `qGreat` · `qFair` · `qOvercast` · `qClean` | #FF5C3F · #FF8A3D · #E6C25A · #6B7886 · #4DA0B0 | 예보 카드 라벨, Visualizer |

**규칙:** 데이터를 그리는 코드와 그 설명(범례, 배지)은 같은 `dataColor` 이름을 씁니다. 한쪽만 값을 바꾸지 않습니다.

밝은 모드에는 `lightDataColor`가 한 벌 더 있습니다. **이름이 같으면 뜻이 같고, 값은 같은 색 계열의 진한 쪽**입니다(예: `summer` #FFA500 → #B45309). 밝은 패널 위의 절기 점, 예보 라벨, 레이어 아이콘, 하늘 탭 시간 슬라이더의 출몰 표시에 씁니다. 지도에 그린 선과 그 범례는 늘 어두운 지도 카드 위에 있으므로 모드와 상관없이 `dataColor`입니다. 그래서 "그림과 범례가 같은 값" 규칙은 어느 모드에서도 지켜집니다.

## 4. 재질 — 네 겹

| 겹 | 토큰 | 성질 | 쓰는 곳 |
|---|---|---|---|
| 바닥 | `color.bg` | 불투명, 가장 어두움 | 앱 배경, 카메라 화면 바탕 |
| 도킹 패널 | `material.panel` | 불투명, 모서리 `lg`, 선 `border` | 아래 조작부, 끌어올리는 시트, 설정 카드 |
| 떠 있는 것 | `material.overlay` | 82% 반투명, 모서리 `xs~sm` | 3D·지도·카메라 위의 버튼, 배지, 범례, 진행 띠 |
| 창 | `material.modal` + `scrim` | 한 단 밝은 `panelRaised`, 선 `borderStrong`, 뒤를 62% 가림 | 설정, 레이어, 위치, 도움말 |

- 겹이 높을수록 조금 밝아집니다(bg → panel → panelRaised). 그림자는 떠 있는 것과 창에만 씁니다.
- 한 겹 안에 같은 겹을 또 올리지 않습니다. 패널 안의 칸은 `fill`(흰 4%)로 나눕니다.

### 4.1 화면 모드 — 어둡게 · 밝게 · 시스템

설정 → 화면 모드에서 고릅니다(`store.themeMode`, 기본값 **어둡게**). 해 질 녘과 밤에 쓰는 앱이라 어두운 쪽이 기본입니다. 밝게는 대낮 밖에서 패널을 읽기 쉽게 하려는 모드입니다.

| 무엇 | 어둡게 | 밝게 |
|---|---|---|
| 헤더, 아래 도킹 패널(시간 슬라이더·지도 조작부), 끌어올리는 시트 | 어두움 | **밝음** |
| 창(설정·레이어·위치·도움말), 기록 탭, 권한 화면 | 어두움 | **밝음** |
| 3D 하늘, 그 위의 HUD·레이어 버튼·진행 띠 | 어두움 | 어두움 |
| 지도 카드(지구본·지도)와 그 위의 배지·범례·메뉴 | 어두움 | 어두움(밝은 바탕 위의 어두운 창) |
| 촬영 화면, 사진 상세 | 어두움 | 어두움 |

- 그림(하늘·지도·사진) 위에 얹힌 것은 **그림 위에서 읽혀야 하므로** 모드를 따르지 않습니다. 사진 상세도 사진 뷰어라서 어둡게 둡니다.
- 밝은 팔레트(`lightColor`, 흰 바탕 대비): `text` 17.9 · `textDim` 7.6 · `textMute` 4.8 · `accent #0369A1` 5.9 · `sun` 5.0 · `glow` 5.2 · `moon` 6.3 · `success` 5.0 · `danger` 4.8 : 1. 어두운 모드와 달리 `textMute`도 4.5:1을 넘습니다.
- 바닥 `bg #E9EEF4` → 패널 `#F8FAFC` → 창 `#FFFFFF`로, 겹이 높을수록 밝아지는 규칙은 같습니다.
- **코드 규칙**
  - 모드를 따르는 부품: `const useStyles = makeStyles((color) => ({ … }))` 로 스타일을 만들고, 부품 안에서 `const color = useThemeColors(); const styles = useStyles();` 로 씁니다(`theme/useTheme.ts`). 데이터 색은 `useDataColors()`.
  - 그림 위의 것: 모듈의 `color`(어두운 값)를 그대로 쓰는 `StyleSheet.create` 로 둡니다. `theme` 을 넘겨야 하면 `OVERLAY_THEME` 을 넘깁니다(예: `SkyScene3D`, 지도 카드 안).
  - `OverlayButton`은 모드와 상관없이 어둡고, `PrimaryButton`·`Chip`·`Panel`·`SectionLabel`은 모드를 따릅니다.
- "시스템"은 OS 설정을 읽습니다(`app.config.js` 의 `userInterfaceStyle: "automatic"`). 이 설정은 **새 네이티브 빌드부터** 먹습니다. 옛 빌드는 OS를 늘 어둡게 읽으므로, 앱 안 업데이트로 받아도 "시스템" = 어둡게가 되어 안전합니다.

## 5. 자리 — 어디서 보고, 어디서 조작하나

탭은 셋입니다(`01 하늘 · 02 예보 · 03 기록`, §143 · 2026-10-25 이름 정리 · 예보 추가). 01 하늘은 한 순간을 깊게, 02 예보는 앞으로 16일 날마다 일출·일몰 판정을 한눈에 보여 줍니다(아래 "02 예보"). 지도 탭은 없어졌고, 지도·구름 레이더·지구본은 하늘을 두 손가락으로 줌아웃하면 같은 화면에서 이어집니다(`zoomContinuum.ts`). 날짜는 헤더가 아니라 아래 날짜·시간 막대(`TimeBar/DateTimeBar`)가 맡습니다. 촬영 화면도 가능한 한 이 규칙을 따릅니다.

| 자리 | 하는 일 | 하늘 | 하늘 — 지도 단계(줌아웃) | 촬영 |
|---|---|---|---|---|
| 헤더 | **앱 전체** — 탭 · 위치 · 설정 | `01 하늘 · 02 예보 · 03 기록`, 위치 버튼(장소 이름 — 저장한 장소 1km 안이면 그 이름, 아니면 짧은 좌표. 폭 360 미만은 핀만), 설정 — 모두 40 | 같음 | 닫기 · 다음 출몰까지(세 시간 넘으면 시각) · 카메라 방위/앙각 |
| 왼쪽 위 | **읽기** | 방위 눈금 한 줄(고도·화각 눈금은 손으로 돌리는 동안만) | 상공 · 구름 레이더 배지, 착륙 | 실제 카메라 · 방위 보정 상태(보정됨/자북 기준/보정 중) · 보정 안내 |
| 오른쪽 위 | **보기 조작** | 레이어 · 구/지도(두 손가락 줌아웃의 누르기 대안) | — | 노출 막대 |
| 왼쪽 아래 | **범례·읽기값** | 진행·오류 띠 | 길게 누르기 안내 | 방위 눈금 · 배율 1·2·3·5 (오른쪽 끝 앞뒤 전환) |
| 아래 도킹 | **시간 조작 + 주 동작** | 날짜·시간 막대 세 줄: ① 날짜 ② 시각(끝의 해 단추 = 일몰·일출 앞뒤 3시간 확대) ③ 정확도 칩 · 지금(SIM 일 때) · **촬영** | 같음 | 화면 보정 · 방위 맞춤 · **셔터** · 예측 보기(살아 있는 3D 칸) |
| 끌어올리는 시트 | **판단 → 언제 → 근거** | 요약 줄: 판정 다섯 칸 · 판정 단어 · 점수 · 가장 붉을 때 → 펼치면 노을 예측(판정·이유) → 이벤트 → 태양·달 수치 | 같음 | — |

- 설정 창 순서: 언어 → 화면 모드 → 알림 → 권한 → 계정 → 앱 정보. 개발자 옵션은 개발 빌드에서만, 맨 아래에 둡니다. 자주 바꾸는 것이 위입니다.
- **끌어올리는 시트는 창처럼 위에 겹칩니다.** 3D 하늘은 시트 요약 줄(`PEEK_HEIGHT` 40px)만큼 비켜 고정되고, 시트는 그 위로 떠서 올라옵니다. 펼친 동안 하늘에 옅은 막(`scrim`)이 깔리고, 막을 누르면 닫힙니다. 예전에는 시트가 자라는 만큼 하늘이 찌그러졌습니다(2026-09-30).
- **3D 라벨은 지금 맨눈에 보이는 것만** 가리킵니다(`utils/labelVisibility.ts`). 행성은 하늘이 그 밝기만큼 어두울 때(금성 해 −2°, 목성 −4°, 토성 −6° 아래), 달은 떠 있고 낮이면 12% 넘게 차고 해에서 20° 넘게 떨어져 있을 때, 은하수 중심은 해 −15° 아래일 때만 라벨이 붙습니다. 판정 `verify-label-visibility`.
- **02 예보:** 제목 · 가장 좋은 때(3~7일 안에서 점수가 가장 높은 출몰) · 날짜 | 일출 | 일몰 표 · 아래 도킹의 "좋음 이상 알림". 칸은 판정 단어 + 다섯 칸 + 가장 붉을 때이고, 확실도는 무늬입니다 — 3일 안은 꽉 찬 칸 + 점수, 7일 안은 빗금, 16일 안은 점선(참고, 점수 숨김). 칸을 누르면 그 시각으로 01 하늘이 열립니다. 예보가 없는 출몰은 "예보 없음"(맑음으로 지어내지 않음). 판정은 01 하늘 요약 줄과 같은 식이고, 그날 링을 받아 두었으면 링으로 세어 숫자도 같습니다(`utils/sunForecast.ts`).
- **촬영:** 카메라가 화면을 채우고, 그 위에 해 경로(점선) · 지금 해(빈 고리 — 진짜 해가 고리 안에 들면 방위가 맞음) · 다음 출몰(지평선 눈금 + 시각) · 방위 눈금을 겹칩니다(`SunPathOverlay`). 3D 예측은 도킹의 "예측 보기" 칸에 작게 살아 있고, 누르면 무대에 펼칩니다. 기기 확인 목록 `docs/CAMERA_FULLSCREEN_CHECK.md`.
- 한 화면에 **주 버튼은 하나**입니다(`PrimaryButton`, 강조색 바탕). 하늘은 촬영, 예보는 좋음 이상 알림, 촬영 화면은 셔터입니다. 해 색(`sun`)으로 버튼을 채우지 않습니다 — 예전 아래 막대의 "지금"·"촬영"이 그랬습니다(2026-10-25 정리).

## 6. 글자 · 아이콘 · 간격

- **글자는 다섯 단계**(`type`)입니다: 9 · 11 · 13 · 16 · 22. 이 밖의 크기는 쓰지 않습니다.
  - 수치, 시각, 라벨, 단위는 **모노**(`micro`, `label`, `display`)로 씁니다. 숫자 자리가 흔들리지 않습니다.
  - 문장은 기본 글꼴(`body`, `title`)로 씁니다.
  - 9(`micro`)는 단위·눈금·구획 머리에만 씁니다. 읽어야 하는 라벨은 11부터입니다.
  - 굵기는 500 · 700 · 800 셋입니다. 900 · 600 · `bold` 는 쓰지 않습니다.
  - 예외는 하나: 시작 화면의 앱 이름(32, 로고 표기).
- **대문자 라벨**(`micro` + `textTransform: uppercase`)은 구획 머리(`SectionLabel`)에만 씁니다.
- **아이콘**은 lucide 한 벌만 씁니다. 크기는 `icon` 다섯 단계입니다. 아이콘 색은 그 아이콘이 나타내는 역할색(§2)이나 `text`/`textDim`입니다.
- **간격**은 `space` 단계만 씁니다. 줄 사이는 `sm 8`, 칸 안 여백은 `md 12`, 화면 가장자리는 `lg 16`입니다.

| **고름·켬** (칩, 토글) | 바탕·테두리 색이 160ms에 걸쳐 바뀝니다. 크기는 그대로입니다. | `Chip` |

| **나타남** (진행·오류 띠, 위치 메뉴) | 8px 아래에서 240ms(enter)로 떠오릅니다. | `Reveal` |

### 8.3 규칙

1. **모든 애니메이션은 `theme/motion.ts`의 `springTo` / `timeTo`를 거칩니다.** 새 코드에서 `Animated.timing` / `Animated.spring`을 직접 쓰지 않습니다. (예외: 3D 장면 내부, 개발자 패널)
2. **몸짓이 끝나 제자리로 돌아가는 것은 스프링, 스스로 끝나는 것(닫힘, 색)은 시간**으로 움직입니다.
3. **동작 줄이기(OS 접근성 설정)를 따릅니다.**
   - 크기나 위치가 움직이는 것은 즉시 끝납니다.
   - 누름은 흐려짐(72%)으로 대신합니다.
   - 색과 투명도 변화는 움직임이 아니므로 남깁니다(`keepWhenReduced`).
4. **되풀이 애니메이션(loop)은 "지금 진행 중"일 때만** 씁니다(예: 재생 중). 쉬는 화면에서 무언가가 계속 깜빡이지 않습니다.
5. **네이티브 드라이버:** 크기, 위치, 투명도는 네이티브 드라이버로 돌립니다(웹은 자동으로 끔). 그래서 3D 장면이 바빠도 누름 반응이 끊기지 않습니다. 색, 폭, 높이는 JS 드라이버(`useNativeDriver: false`)로 돌립니다.
6. **길게 누르기**는 700ms(`OverlayButton` 기본)입니다. 지도 위치 버튼만 350ms입니다(메뉴를 부르는 주 몸짓이라서).

### 8.4 진동(햅틱)

세 군데만 떱니다(`utils/haptics.ts`, 2026-10-25 · 3단). 누를 때마다 떨면 아무것도 알리지 못합니다.

| 언제 | 무엇 | 자리 |
|---|---|---|
| 셔터를 누름 | impact medium | 촬영 화면 |
| 시간 막대 손잡이가 일출 · 일몰 표시를 지남 | selection | 날짜 · 시간 막대(시각 줄) |
| 사용자에게 알리는 오류 | notification error | 촬영 실패 · 올리기 실패 · 날씨를 못 받음(하늘 · 02 예보) |

- **옛 빌드에서도 멈추지 않습니다.** 앱은 `expo-updates` 로 새 JS 를 받고 `runtimeVersion` 이 고정이라, 햅틱 모듈이 없는 옛 스토어 빌드도 이 JS 를 받습니다. `expo-haptics` 15 는 네이티브 모듈을 선택적으로 찾으므로(`requireOptionalNativeModule`) 불러오기만으로는 죽지 않고, 호출의 거절은 `haptics.ts` 가 삼킵니다 — 옛 빌드에서는 진동만 없습니다. 진동이 실제로 나는 것은 새 스토어 빌드부터입니다.
- 동작 줄이기와는 따로입니다(진동은 움직임이 아님). OS 의 진동 끔 설정은 OS 가 따릅니다.

## 9. 말투

- **세 언어**(한·영·일)를 모두 채웁니다. 새 문구는 `t(key, language)`, 한 번만 쓰는 문구는 `L3(language, 한, 영, 일)`로 넣습니다. `language === 'ko' ? … : …` 식은 쓰지 않습니다(일본어 사용자에게 영어가 나옵니다).
- **시각은 관측지 현지 시각**(`timezoneOffsetHours`)으로 적습니다. UTC는 필요할 때만 곁에 작게 적습니다.
- **HUD 문체**(모노, 영어 약어)는 수치 라벨에만 씁니다(`FOV 60°`, `1.0x`, `LIVE`). 문장이나 버튼 이름, 카드 라벨(예전 "SUNSET FORECAST · COLOR")은 번역합니다.
- **이모지는 쓰지 않습니다.** 알림 제목, 공유 문구, 안내 띠도 같습니다. 필요한 곳은 lucide 아이콘을 글자 옆에 둡니다. SNS 캡션의 해시태그는 그대로 둡니다.
- **버튼 이름은 일어날 일**을 말합니다("재생", "방위 맞춤", "로그인").

## 10. 접근성

- 누르는 것은 최소 40px(`TOUCH`)입니다 — `hitSlop` 이 아니라 실제 크기입니다. 예외는 32px 떠 있는 버튼(`OverlayButton`) 하나로, `hitSlop` 4px로 넓힙니다. `Chip` 도 높이 40입니다.
- 아이콘만 있는 버튼은 `accessibilityLabel`을 세 언어로 답니다.
- 고른 상태는 `accessibilityState.selected`로 알립니다(`OverlayButton`, `Chip`).
- 글자 대비: 본문은 `text`, 설명은 `textDim`까지 씁니다. `textMute`는 단위나 꺼진 것에만 씁니다. 어두운 모드 `textMute` 는 `#778699`(bg 5.3 · panel 5.0 · panelRaised 4.6 : 1), `qOvercast` 는 `#7D8BA0`(panel 5.4 : 1)입니다 — 예전 값은 4.5:1에 못 미쳤습니다(2026-10-25).
