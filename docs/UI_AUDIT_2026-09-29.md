# 인터페이스 최종 점검 (2026-09-29)

사용자 요청: "앱의 인터페이스 기능 메뉴위치 등을 전체적으로 최종 점검해."

## 방법

- 앱 전체(`src/App.tsx`)를 esbuild + react-native-web 으로 웹에 띄웠습니다. 네이티브 전용 모듈(지도, Skia, 위젯, Firebase 등)은 흉내 모듈로 바꿨습니다.
- Playwright 로 탭·헤더 버튼·시트·모달을 눌러 가며 화면을 찍었습니다.
  - 화면 크기: 390×844, 360×640, 320×640, 1280×800.
  - 언어: 한국어, 영어.
- 촬영(CAM/AR) 화면은 웹에서 카메라 모듈이 돌지 않아 코드로만 봤습니다.
- 날씨는 네트워크가 막힌 상태("날씨를 받지 못했습니다")에서 봤습니다.

## 화면 구성

| 자리 | 요소 |
|---|---|
| 헤더 1줄 | 탭 `01 SKY · 02 MAP · 03 LOG`, 📍 위치 변경(모달), ⚙ 설정(모달) |
| 헤더 2줄 | ‹ 날짜 › (누르면 달력), 시간대 표시, 오늘로 |
| SKY | 3D 하늘, 오른쪽 위 레이어 버튼, 아래 시트(요약 한 줄 → 끌어올리면 노을 예측·태양·달·이벤트), 타임 슬라이더, CAM/AR 버튼 |
| MAP | 선택 날짜·시각(UTC) 줄, 지도/지구본 카드(배지·📍·🌐/🧭·ⓘ), 범례, 춘분~동지·날짜·시각 슬라이더·재생 |
| LOG | 노을 갤러리(전체/내 사진) |
| 설정 | 계정, 패밀리 서비스, 언어(한/영/일), 앱 권한, 앱 정보 (개발자 옵션은 개발 빌드만) |

## 고친 것 (이 PR)

1. **SKY 시트의 "추천 이벤트"가 계산이 아니라 고정 문구였습니다.**
   - 날씨·달과 무관하게 늘 "훌륭한 일몰 · 추천 95점", "훌륭한 일출 · 90점"이 떴습니다.
   - "은하수 관측 적기"는 보름에도 떴고, "행성 & 야경"은 늘 22:00이었습니다.
   - 출몰 시각을 모르면 06:12·19:35 같은 지어낸 시각을 썼습니다.
   - `skyEvents.ts` 가 계산으로 만들도록 바꿨습니다.
     - 일몰·일출: 그 시각의 노을 예측이 있으면 품질과 점수, 없으면 "날씨를 받으면 예측".
     - 가는 달: 초승달은 저녁 서쪽, 그믐달은 새벽 동쪽.
     - 은하수: 천문 박명 뒤 달이 없거나 아주 가늘 때만.
     - 행성: 박명 뒤 10° 넘게 뜬 것만, 이름을 적어서.
     - 일반: 실제로 있는 출몰만.
   - 판정 `verify-sky-events` 11/11.
   - 원래 점수 뱃지는 화면에 그려지지도 않았는데, 이제 그립니다.
2. **MAP 이 헤더 날짜를 따르지 않았습니다.** 헤더에서 10/01로 넘겨도 지도는 9/29였습니다. 이제 헤더가 30분 넘게 건너뛰면 지도도 따라갑니다. 실시간으로 1분씩 흐르는 것은 따라가지 않습니다.
3. **360·320px 기기에서 지도 배지가 📍 버튼을 덮었습니다.** 원인은 두 가지였습니다. 폭 상한을 화면 폭으로 계산했고(카드가 28px 좁음), 배지가 줄바꿈을 못 해 상한이 먹지 않았습니다. 둘 다 고쳐 이제 두 줄로 접힙니다.
4. **출시판에서도 레이어 버튼을 길게 누르면 개발자 튜닝 패널이 열렸습니다.** 이제 `__DEV__` 에서만 열립니다.
5. **마이크 권한:** 앱은 소리를 녹음하지 않는데, `expo-camera` 가 RECORD_AUDIO 를 매니페스트에 넣었고 설정에 "오디오 & 마이크" 줄이 있었습니다. 둘 다 뺐습니다(`app.config.js` 의 제거 목록). Play 콘솔 권한 신고에도 영향이 있습니다.
6. **번역:** 영어·일본어로 바꿔도 SKY 시트 전체가 한국어였습니다. 다음 문구를 번역 키로 옮기고 영·일을 채웠습니다.
   - SKY 시트(태양·달, 이벤트, 진행·오류 문구, 추적 표시).
   - 3D 레이어 창.
   - 지도 레이더와 시뮬레이션 문구.
   - 기존 오타 `moonset: '월목'` 을 '월몰'로 고쳤습니다.

## 후속 — A~G 처리 (같은 날)

- **A 번역**
  - 촬영 화면(SunCamera)과 사진 상세(PostDetailModal)를 세 언어로 바꿨습니다.
    - 새 도우미 `L3(lang, 한, 영, 일)` 를 씁니다.
    - 예전의 `language === 'ko' ? 한 : 영` 식은 일본어 사용자에게 영어를 보여 줬습니다.
  - 점검 중 가짜 값도 찾아 없앴습니다.
    - 사진 상세의 기상 칸이 늘 운량 35% · 시정 15km · 'Vivid 붉은 노을' 이었습니다(저장되는 자료에 그 필드가 없음).
    - 습도는 이미 % 인 값에 100 을 곱해 5000% 처럼 나왔습니다.
    - 좌표가 없으면 서울 좌표, 이름이 없으면 '서울특별시' 를 썼습니다(촬영 화면 업로드에도 같은 기본값).
    - 이제 저장된 값(보간 기상 · 촬영 습도 · 노을 점수)만 적고, 없으면 '—' 를 씁니다.
  - `isMyPhoto` 가 `|| true` 로 늘 참이라 남의 게시물에도 "공유하기(→ 전체 공개)" 가 떴습니다. 이제 서버 게시물은 userId 로 가립니다.
- **B 지도 시각**: 관측지 현지 시각으로 바꿨습니다.
  - 슬라이더 값, 절기 버튼, 날짜 슬라이더, 등시선 하루치(현지 자정부터), 지도·구 위 시각 라벨이 모두 현지 시각입니다.
  - UTC 는 시각 라벨 옆에 작게 둡니다.
  - 기기 시간대가 아니라 관측지 `timezoneOffsetHours` 로 셉니다.
  - 웹 실측: 하늘 탭 22:40 = 지도 22:40 (· 13:40 UTC).
- **C**: "선택된 날짜 · 선택된 시각(UTC)" 줄을 뺐습니다. 그만큼 지도가 커집니다.
- **D**: 지도 카드의 위치 버튼을 📍 에서 조준점(⌖)으로 바꿨습니다. 헤더 📍 는 위치 변경 창 그대로입니다.
- **E**
  - 탭 이름을 `01 하늘 · 02 지도 · 03 기록` / `01 SKY…` / `01 空 · 02 地図 · 03 記録` 로 바꿨습니다. 번호는 HUD 문체로 남겼습니다.
  - `DATE //` 접두어를 뺐습니다. 320px 에서 두 줄로 깨지던 것도 해소됐습니다.
  - 늘 켜져 있던 `READY` 표시등을 뺐습니다.
  - 헤더·셔터 버튼의 접근성 라벨도 언어를 따릅니다.
- **F**: 3D 라벨이 언어 설정을 따릅니다("태양 Sun" → "태양" / "Sun" / "太陽").
- **G**: 갤러리·사진 상세의 공유 문구를 언어별로 바꿨습니다. 갤러리 쪽은 `item.location`(없는 필드)을 읽어 늘 '하늘 포토' 가 붙던 것도 고쳤습니다.
