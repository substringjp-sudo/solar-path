## 2. 크게 고려할 것 (결정 필요)

- **runtimeVersion 이 고정 문자열 `"1.0.0"`** — 네이티브 모듈이 바뀐 빌드에 옛 OTA 가 내려가면 앱이 죽을 수 있습니다.
  `{ policy: "appVersion" }` 또는 `"fingerprint"` 권장. 바꾸면 기존 설치본은 새 스토어 빌드 전까지 OTA 를 못 받습니다.
- **의존성 버전 불일치** — `npx expo install --check` 가 SDK 54 권장 버전과 다른 패키지를 보고합니다.
  `npx expo install --fix` 후 **네이티브 빌드로** 확인하세요(웹 번들만으로는 부족).
- **공개 사진 1시간 뒤 공개는 앱에서만 걸러집니다** — 서버 규칙상 `global_photos` 는 올리자마자 누구나 읽을 수 있습니다.
  방침에 "1시간 뒤 공개"라고 적었으니, 규칙에 `resource.data.createdAt < request.time - duration.value(1, 'h')` 를
  넣거나(자기 사진은 예외) 방침 문구를 바꾸세요. 쿼리 쪽도 같은 조건이 있어야 규칙이 통과합니다.
- **Google Maps API 키 제한** — 앱 패키지명·SHA-1 으로 제한돼 있는지 Cloud 콘솔에서 확인.
- **태블릿 지원(`supportsTablet: true`)** — App Store 에 iPad 스크린숏이 필요합니다. 준비가 안 됐으면 끄세요.
- **스토어 등록정보에 일본어가 없음** — 앱은 ja 를 지원합니다. ja-JP 등록정보를 추가하면 좋습니다.

## 3. 이 브랜치에서 고친 것

### 3.1 보안
- `storage.rules`: 사진 올리기를 **본인·JPEG/PNG·15MB 미만**으로 제한(익명 로그인으로 아무 파일이나 무한히 올리던 구멍).
- `firestore.rules`: `reports` 컬렉션 — 로그인한 사람만 만들 수 있고, 필드 모양 고정, 앱에서는 읽기·수정 불가.
- 서비스 계정 키 추적 해제(B1 참고).

### 3.2 Play 정책
- **앱 안 계정 삭제**(설정 → 계정 삭제): 공개 사진 → 내 사진·장소 → 저장소 파일 → 인증 계정 순으로 지웁니다.
  오래 전에 로그인했으면 다시 로그인하라고 안내합니다(`requires-recent-login`). — `src/utils/accountDeletion.ts`
- **사용자 제작 콘텐츠 신고·차단**: 남의 사진 상세에서 깃발 → 사유 선택 → 신고(그 사진은 바로 숨김),
  "이 사용자의 사진 모두 숨기기". 숨김·차단 목록은 기기에 저장돼 갤러리 동기화에서도 빠집니다.
- **사진 권한 최소화**: 사진은 저장만 하므로 `writeOnly` 로 요청하고 `READ_MEDIA_IMAGES` 를 매니페스트에서 뺐습니다
  (Play 의 사진·동영상 권한 정책).
- 설정 → 앱 정보에 **개인정보처리방침·계정 삭제 안내** 링크, 버전은 빌드 설정에서 읽습니다.
- 공개 사진 이름을 기본 `Anonymous` 로(표시 이름이 없으면).
- `public/delete-account.html` 에 앱 안 삭제 경로 추가.

### 3.3 다국어
한국어로만 나오던 사용자 문구를 en/ja 로:
하늘 진행 표시(`skyTimeline`), 카메라 장면 배지, 공유·저장 알림창, 지도 저장 알림,
위젯·노을 알림의 기본 문구, 위젯 첫 화면(가짜 시각 `19:25` 대신 `--:--`, 기기 언어),
지도 태양 방위 그림(일출/정오/일몰, 방위각/고도/그림자), 지도 위 태양 부채꼴 라벨,
일본어 문자열에 섞여 있던 한글 오타 4곳.
