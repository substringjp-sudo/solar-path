# 파동 합성 구름 장 설계 (2026-11-11, 1판)

사용자와 정한 방향: 가까운 구름(반경 약 50 km, 저층·중층)의 모양을 종류별 손무늬 대신 **자료로 손잡이를 정한 사인 파동 합성 장**에서 만든다.
먼 곳·높은 곳의 2차원 구름은 그대로 둔다. 코드: `src/components/VolumetricProbe/cloudWave.ts`(하네스 시제품, 층 `opts.wave` 가 있을 때만 켜짐, 기본 꺼짐).

## 1. 자료에서 만드는 손잡이

| 기호 | 뜻 | 만드는 법 |
|---|---|---|
| `z_b`, `z_t`, `H` | 구름 밑면·윗면·두께 | 응결 높이와 습도 단면 |
| `z_i` | 경계층 높이 | 예보 |
| `U(z)` | 높이별 바람 | 850·600·250 hPa 보간 |
| `S` | 바람 차이 | `(U(z_t) − U(z_b)) / H` |
| `N` | 안정도 | `N² = (g/θ)·dθ/dz` |
| `w*` | 상승 기류 세기 | `0.1·√(2·CAPE)`, 아래 한도 0.3 m/s(지표 현열을 받으면 정식 식) |
| `C(x,y)` | 운량 | 고리 예보 격자 |
| `χ` | 대류성 0(판)~1(뭉게) | `w* / (w* + N·H)` — **시제품에서는 직접 줌**(이 식은 뭉게구름에서도 0.2~0.3 으로 낮게 나와 다시 정해야 함) |

## 2. 파동

크기 단계 `j = 0…5`, 단계마다 방향 12 개.

```
λ_0 = 2.5·z_i,   λ_j = λ_0 · 2^(−j) · (1 ± 0.15 무작위)
a_j ∝ 2^(−j·h),  제곱합 1         h = 1 (시제품 2차; h = 1/3 은 조각으로 흩어짐)
w_j = w*·(λ_j/λ_0)^(1/3)
α_j = 1 + min(3, |S|·λ_j / w_j)          바람 차이 방향으로 늘임
β_j = clamp(N·λ_j / (2π·w_j), 1, 4)      위아래로 누름
```

방향은 구 위에 고르게 흩은 단위 벡터에서 바람 차이 방향 성분을 `1/α`, 수직 성분을 `β` 배.

## 3. 장

```
x'' = x + Σ_{j=0,1} Σ_m 0.15·λ_j/4 · ê_jm · sin(k_jm·x + φ'_jm)      (비틀림, ê ⟂ k)
F_j = Σ_m cos(k_jm·x'' + φ_jm) / √6
F_큰 = Σ_{j≤2} a_j F_j  (단위 분산으로 맞춤)
G   = (exp(κ F_큰) − e^{κ²/2}) / √(e^{κ²}(e^{κ²}−1)),   κ = 0.6 χ     (상승은 좁고 세게)
B   = Σ_{j=3,4} a_j · bump · (2|F_j| − 1.596)                       (둥근 혹 사이 날카로운 골, 평균 0)
```

**고침(1판 초안 대비)**: 초안의 `1 − 2|F|` 는 능선이 뾰족한 꼴이라 혹이 아니라 칼날이 됨 → `2|F| − 평균`(둥근 혹, 날카로운 골).
단계 5(~λ_0/32 ≈ 90 m)는 행진 보폭보다 짧아 반짝이는 점으로 깨져서 뺌.

## 4. 장에서 구름으로

```
z_b(x,y) = z_b + σ_b·(1−χ)·F_큰(x,y,z_b)                (판 구름 밑면 굴곡, σ_b 120 m)
μ        = χ · clamp((z − z_b(x,y))/H, 0, 1)             (판은 기둥 통째로 — χ 를 곱하지 않으면 95 % 덱이 구멍 난 스펀지)
V        = (1−μ)·G(x,y,z_b) + μ·G(x,y,z) − max(0,(z_b−z)/50 m) − max(0,(z−z_t)/(0.3H))
τ        = 기둥 최댓값 V 의 분포에서 위쪽 C 만큼을 남기는 값
s        = V − τ + χ·B                                     (B 는 표면 근처 −1.2 < V−τ < 0.6 에서만 계산)
q        = (0.25 + 0.75·((z−z_b)/H)^{2/3}) · clamp(e·s, 0, 1) · (1 + 0.3(1−χ)·tanh V)
```

밀도 `q` 에 층 소광(`densityScale`)을 곱해 그림. `e` 는 꼭대기 위 습도로 정할 예정(시제품 3).

## 5. 결과물(시제품)

- `V` 를 CPU 에서 192 × 192 × 40 칸 R16F 3차원 텍스처로 구움(반 폭 15 km, 가로 156 m·세로 약 55 m, 거울 반복). 굽는 시간 하네스 2.5~3.1 s.
- 작은 파동 `B`(24 개)는 셰이더에서 바로 계산.
- 앱에 넣을 때는 굽기를 그래픽카드로 옮기고(장면당 한 번·몇 초마다), 상자 밖 처리와 시간 변화(바람 이동·위상)를 더함.

## 6. 시제품 1차 결과 (2026-11-11, 하네스 420×600, 13:01 수원 장면, `docs/evidence/wave-field-proto-r1.jpg`)

| 회차 | 바꾼 것 | 결과 |
|---|---|---|
| 1 | h = 1/3, 단계 0~5 | 잰 운량 35 %·95 % 정확. 뭉게구름이 작은 조각 무리로 흩어지고 가장자리가 반짝이는 점 |
| 2 | h = 1 | 한 덩어리 몸통에 둥근 혹이 붙음. bump 3·h 0.6 은 다시 조각남 |
| 3 | 단계 5 뺌, 판 구름 μ 에 χ 곱함 | 뭉게구름 반짝임 줄어듦. 95 % 가 덱이 됨 |
| 4 | 흐림 장면 층 종류를 ns·st 로(빛 항 thru 1) | cu 층(thru 0)에서 덱이 푸르게 보이던 것은 빛 항 차이 |

남은 문제:
1. 뭉게구름 표면의 잔 알갱이(takram 잔무늬를 뺀 상태라 행진 표본 잡음이 그대로 보임).
2. 흐림 덱 구멍 가장자리가 너무 날카로움(`e` 3, 밑면 50 m) — 판에서는 `e` 를 낮춰야 함.
3. 흐림 덱이 지금 방식과 비교해 나아졌다고 말할 수준은 아님. 빛(먼 구름 가림, 덱 아래 빛)이 함께 가야 함.
4. 판정은 사용자 눈. 자(지표)는 아직 없음.
