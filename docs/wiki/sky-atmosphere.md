## 지금 상태(출처 목차 · 머리 문장 요약 — 본문 대조 필요)
- 대기 표: takram three-atmosphere(Bruneton). 3파장 표는 박명이 자주색으로 뜸 → **15파장 분광 표**(§128, `spectralAtmosphere.ts`). 하네스 `load` 인자는 3파장이라 쓰지 말 것.
- 박명 곡선: 해 진 직후 너무 빨리 어두워지던 것 — 다중산란 척도고도, 오존 τ 밴드 적분(TWILIGHT.md).
- 노을 색: 대비 · 방위각 감쇠(반대편 번짐 막기, §24) · 고도 축(따뜻함은 단일산란 · 지렛대는 에어로졸, §26) · 초록 · 카키 기 제거(§16).
- 스치는 햇빛: 둥근 대기를 지나는 광선, 자리마다 다른 해 고도(§105 · §106). 해 쪽 먼 구름 가림(§103).
- 표시 곡선: AgX · ACES · Neutral 을 사진 밝기비로 잼(§125), 앱은 ACES. 색상 보존 톤 곡선(§122). 카메라 화이트밸런스(§89 · §30).
- 미세먼지 · 연무(§146), 태양 원반 보임 조건 · 분광 색(§151 · §152), 자동 노출 표 `AUTO_EXPOSURE_POINTS`(해 고도별)는 맑은 하늘을 위로 볼 때 기준이라 땅을 내려다보면 해가 지평선에 닿을수록 화면이 도리어 밝아짐(맥북 실측 평균 0.04→0.16). **2026-11-27 노출 방식 분리**: 시뮬레이션 = 표 × 화면 평균 휘도 측광(`exposureMeter.ts`, 목표 범위 0.1~0.25 밖만 보정, ±2 EV, 해 −6°→−1° 구간에서 측광 서서히 끔 — 지평선 아래 깊은 밤은 표대로), 샌드박스 = 자동 노출 없이 고정(`MANUAL_EXPOSURE_BASE` 7.2 × 2^EV, 설정 창 "샌드박스 노출" 슬라이더 −4~+12 EV). 개발 패널 칩 "노출 측광"으로 표만 쓰는 옛 방식과 비교. 측광은 읽기를 다음 프레임에(맥북 Chrome 에서 `readRenderTargetPixelsAsync` 가 0 만 돌려줘 동기 읽기). 남은 일: 지평선(해 0°) 튐이 2.8배 → 약 1.7배로 줄었을 뿐 완전히 없지 않음, 기기 확인 전.
- 지금 남은 것: 해 진 뒤 분홍은 '아치 빛'(§174) — T_sun · 아치 빛은 하네스 전용 도구, 기본 끔(§176~§181).
