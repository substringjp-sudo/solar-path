# 밤하늘 — 달빛 · 별 · 암순응

한 줄: 달빛과 광공해로 별 한계등급을 깎고, 밤 구름은 달빛으로 칠하며, 사람 눈의 암순응을 흉내낸다. 갱신: 2026-11-26

## 지금 상태(출처 목차 · 머리 문장 요약 — 본문 대조 필요)
- 한계등급을 달빛으로 실시간 깎음(§12). 별 보기 계산 과정(구름 · 달빛 · 빛 공해 · 연무 → 보이는 별 등급, SANDBOX §9).
- 밤 구름이 기괴하게 빛나던 것 · 달이 구름 앞에 있던 것(§92), 흐린 보름밤 하늘 새카맣고 땅 하얗던 것(§99).
- 눈으로 보는 밤: 간상체 암순응 · 밤의 색 빠짐(§95, 밝기 ×1 선택).
- 지구본 달빛 범위 · 위상, 지도 · 공중 구름 밤에 어둡던 것(작업 기록).
