# BeforeGlow LLM 위키 — 규칙(스키마)

이 폴더는 **에이전트(LLM)가 읽고 고쳐 나가는 주제별 위키**입니다. 원본 계획 문서(`docs/*.md`)는 **바꾸지 않는 출처**로 두고,
위키는 그 출처들을 주제별로 녹여 "지금 무엇이 참인가"를 짧게 적습니다. 사람도 읽지만, 1차 독자는 다음 세션의 에이전트입니다.

## 층 셋
1. **출처**(raw) — `docs/*.md`, `docs/evidence/`, `tools/**/RULER-*.md`. 시간순 작업 기록이라 길고 겹칩니다. 위키에서 고쳐 쓰지 않습니다.
2. **위키** — `docs/wiki/*.md`. 주제마다 한 장. 현재 상태 · 핵심 수치 · 코드 위치 · 결정 · 남은 일 · 출처 절 번호.
3. **이 규칙** — `docs/wiki/README.md` 와 저장소 뿌리 `CLAUDE.md`.

## 쪽 형식
- 맨 위 한 줄 요약, `갱신: YYYY-MM-DD`.
- 절: **지금 상태** → **핵심 수치 · 식** → **코드** → **결정과 이유** → **남은 일** → **출처**.
- 출처는 `docs/파일.md §절` 꼴. 코드는 `src/...` 경로(줄 번호는 바뀌므로 함수 · 상수 이름으로).
- 다른 위키 쪽은 상대 링크 `[구름 빛](cloud-lighting.md)`.
- 확인하지 않은 내용은 "(출처 목차에서 요약 — 본문 미확인)"처럼 표시. 추측을 사실처럼 쓰지 않습니다.

## 작업 세 가지
- **받아들이기(ingest)**: 작업을 끝내면(코드 · 계획 문서 절 추가 · PR) 관련 위키 쪽의 "지금 상태 · 수치 · 남은 일"을 고치고, `log.md` 에 한 줄.
  새 주제면 쪽을 만들고 `index.md` 에 줄을 더합니다. 계획 문서 새 절도 그대로 쓰되, 위키에는 결론만.
- **묻기(query)**: 질문에 답할 때 `index.md` → 해당 쪽 → 출처 절 순으로 읽습니다. 좋은 답(비교 · 원인 분석)은 해당 쪽에 다시 적어 둡니다.
- **점검(lint)**: 가끔 — 쪽끼리 모순, 낡은 수치, 출처 없는 주장, 고아 쪽(색인에 없음), 코드에서 사라진 이름을 찾아 고칩니다. 결과는 `log.md`.

## 쓰는 말
사용자와는 한국어. 쉬운 말, 짧은 문장. 전문 용어는 처음 나올 때 풀어 쓰고 [용어집](glossary.md)에 둡니다.
