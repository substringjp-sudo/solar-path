# 지형 · 땅 · 바다 · 운해

한 줄: DEM 높이장으로 지형 · 해안을 만들고, 하늘과 같은 빛으로 칠하며, 구름과 거리로 겹친다. 갱신: 2026-11-26

## 지금 상태(출처 목차 · 머리 문장 요약 — 본문 대조 필요)
- **땅 계획**: 디테일이 아니라 정보를 더함 — 지평선 아래가 무엇인지 읽히게(GROUND_PLAN, 1~5단계 완료). 먼 바다가 산으로 오인되던 것, 하루 전체에서 통하는 지형 · 바다.
- **해안선**: 93점이 아니라 진짜 높이장, 경계를 그리지 말고 지형과 해수면이 만나게. 물가 거리장(SDF), 해발 0 m 이하가 다 물은 아님, 가시 울타리 · 면 뒤틀림 고침(COASTLINE_PLAN §1~§13, §157).
- **겹침**: 구름이 산을 덮게, 그리는 순서가 아니라 거리로(§116 · §117). 해가 산을 뚫던 것 — 깊이 버퍼(§64). 올려다본 구름을 가까운 산이 가림(§84).
- **운해**: 산 위에서 구름 바닥 내려다보기, 윗면을 단면에서, 땅이 가림, 사진으로 잰 밝기, 층 사이 빛(§81~§88 · §93 · §118).
- **같은 빛**: 지형 · 바다를 볼륨 하늘과 같은 빛으로(§129), 땅을 하늘과 같은 질감으로(§157).
- 지형이 사라지던 것(앱 내렸다 올림, §100). 건물 · 먼 건물 · 건물 고르기는 샌드박스 계획.
