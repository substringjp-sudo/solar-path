# 용어집

| 말 | 뜻 |
|---|---|
| τ(광학 두께) | 빛이 지나며 줄어드는 정도. 직진광은 e^(−τ). 구름 몸통 τ ≳ 10 이면 해를 가린 실루엣 |
| tauCore / tauRendered | 미세물리 기둥 τ(봉투 전) / 렌더 봉투(종류 단면)를 곱한 기둥 τ |
| 기둥(column) | 한 점 위 · 아래로 수직으로 잰 구름 양 |
| 종류(genus) | 구름 운형: cu 적운, sc 층적운, st 층운, ns 난층운, ac 고적운, as 고층운, ci 권운, cs 권층운, cg 웅대적운, cb 적란운, cbanvil 모루 |
| 레인(lane) | 셰이더 vec4 의 층 채널 하나(x · y · z · w) |
| 날씨 값 lw | 날씨 텍스처의 구름 세기(0~1). 문턱 1 − hs 를 넘으면 구름 |
| 흐름 모형(flow) | 기압장 합성으로 날씨 무늬를 만드는 모형(§130) |
| 세포(cells) | 고적운 · 층적운을 쪼개는 Voronoi 무늬 |
| 판 확산 · 두-흐름 | 수평으로 넓은 구름 속 확산광을 위 · 아래 두 흐름으로 근사 |
| 해 쪽 추적(sun march) | 표본에서 해 쪽으로 걸으며 τ 를 쌓음 |
| 그림자 지도(BSM) | takram 의 해 쪽 두께 지도. 물리 빛 모드에서는 구름 자기 그늘에 안 씀 |
| farSun | 먼 거리(12~420 km) 해 쪽 구름 가림 지도 |
| 자(ruler) · 판정 | 고치기 전에 동결한 지표 · 문턱 / 그것을 재는 스크립트 |
| 하네스(harness) | 앱 코드를 헤드리스 브라우저에서 돌려 그림을 뽑는 도구(volsky · web-repro) |
| 바이트 동일 | 옵션을 끄면 셰이더 글자 · 날씨 바이트가 예전과 똑같음 |
| 고리(ring) | 관측점 둘레 91점 예보 |
| DNI | 직달일사 — 위성 관측으로 구름 두께 보정 |
| 미세물리(physics) | 액체수 · 물방울 크기로 소광을 세는 모드(개발 패널 "물리 밀도") |
| 렌더 보정 | 렌더가 깎는 밀도 몫을 되돌려 몸통 τ 를 미세물리 값으로(§25.9) |
